# Native reconstruction is NOT_RUN

No independent basic-chat endpoint is available. A clear English key plus an
exact software inverse does not verify model behavior. The author knowing the
source cannot supply a blind trial by describing how it would decode.

Freeze native-packet.txt as the sole input to a fresh basic chat: no system
instructions, tools, skills.md, source attachment, external dictionary or
training. Save the model/version/settings, exact response and latency. Compare
UTF8 bytes to the HTTP source without trimming, code-fence stripping or newline
normalization. Any repair/retry is a new trial. Reuse X156/X157 frozen packets
as outstanding tests too, not inherited passes. One successful trial would be
finite behavioral evidence, not correctness for all models or inputs.
