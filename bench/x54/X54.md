# X54 — ATHROISMOS: the column that is its own history

## Summary

X54 ships **ATHROISMOS** (`src/lib/omega/athroismos.ts`, key
`athroismos`, exact, deep): elision of **driven first-order recurrence
columns** in delimited tables — `y_i = y_{i-1} ± x_i` and
`y_i = y_{i-1} + credit_i − debit_i` — the balance/running-total columns
of the statements and exports pasted into chats every day. Inventory
proof of novelty: APOGRAPHE's complete predictor union is {above, col,
days, workdays, int, lin, clock} (read from source this turn);
SYLLOGISMOS/TAXIS are strictly same-row; HEMERA/HORA ship date deltas
as payload. No predictor in the 283-module stack combines previous-row
state with a same-row driver. ATHROISMOS fits the recurrence in exact
BigInt decimal arithmetic (plain or German 1.234,56 rendering), ships a
stated start value and up to 3 exception rows (real fixtures contain
balance breaks), and has the reader re-integrate the column downwards.

## A. Formal Model

Same frame as X51–X53 (§A there). ATHROISMOS is admissible on a
delimited table T (delimiter in {comma, tab, semicolon, pipe}, header +
≥8 data rows, single-line records, consistent field counts) when a
target column y and drivers satisfy, in scaled-integer arithmetic at a
uniform scale s (plain or German rendering, re-render checked per
cell):

- cum1: y_i = y_{i−1} + σ·x_i, σ ∈ {+1, −1}; cum2: y_i = y_{i−1} + a_i − b_i;
- empty driver cells count 0; the chain starts from a constant C
  ("running value before data row 1") fitting row 1 exactly;
- at most 3 exception rows may violate the step; their printed values
  ship in the contract and the chain resumes from the printed value;
- guards: ≥3 distinct y values, ≥3 rows with nonzero step.

Reduced = table minus column y (raw field spans of kept columns
preserved byte-exactly). Acceptance requires whole-input restore ==
input. Emission: cheapest measured parent on reduced + contract must
strictly beat AKOLOUTHIA-2 and APOGRAPHE on the source, then the full
TAGSTACK+SIBLING frontier, else the measured best parent.

## D. Negative Space

Modal shortcut here: "ship the deltas instead of the values" — that is
substitution (DIASTEMA/HEMERA own it) and still pays per-row payload.
Detector: in the reduced text, the target column must be *absent*, and
restoration must use only the driver columns + one constant (+ ≤3
exceptions); if any per-row residue of y is needed, it isn't elision.
15 look-alikes checked: APOGRAPHE `above` (copy, no driver), `int`
(constant step only), `col` (same-row copy), `lin/clock` (index
functions), `days/workdays` (date steps), DIASTEMA (interval payload),
HEMERA/HORA (date delta payload), CHRONOS-Ω (temporal deltas + glyph
substitution), SYLLOGISMOS arith (same-row binary), SYLLOGISMOS
row-difference rule (y from *same-row* fields of adjacent rows? — its
"difference" family is y = {x} − {x} of previous row expressed as a
*same-row* insert; it cannot accumulate), TAXIS arith, METRON absolute
generators (explicitly anti-state per its header), KOLUMN column
dictionaries, DAEDALUS/AKO2 dictionaries over digits, ENTHYMEME
convention entailment, GRAMMA layout. The driven recurrence is in none.

[Note: SYLLOGISMOS registry label mentions "a row-to-row difference"
family — y_i = x_i − x_{i−1} form. That is a *difference of the driver*,
computable looking one row up; it is not an accumulation of its own
previous values and cannot reconstruct a balance column, which is the
inverse operation (prefix sums). The distinction is exact: differences
lose the constant of integration and any error stays local;
integrations require the seed and carry state. ATHROISMOS is the
integration direction.]
