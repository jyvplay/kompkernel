## New codec and fresh verification

`src/lib/omega/pinakas.ts` implements classical Schensted row insertion and a
reverse-bumping decoder. Source fields become semistandard insertion rows plus a
recording row sequence. The recording sequence is fully paid, encoded as fixed-
width decimal digits. Both space and LF fieldizations retain empty fields; block
sizes are 32/128. No hidden dictionary, skill file or system prompt is assumed.
This is distinct from the BBWT/LF-cycle mechanism, but not new mathematics and not
an exhaustive semantic-novelty proof against every module.
