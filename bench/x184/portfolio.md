# Six mechanism-distinct executable branches

These are experimental branches of the design, **not Git branches**. All work is
on the session branch. KARTES is new code; the other five deliberately reuse
existing mechanisms instead of relabeling parameter settings as discoveries.
Each runs independently on the same37 sources, including two newly fetched whole
documents. They do not share learned dictionaries or tune one another's outputs.
`portfolio.ts` provides the shared measurement interface, not a shared mechanism.

Actual experiments: six direct-wire families on all37 sources, with every
available plan byte-round-tripped and token round-tripped; selected full-parent
trials on email and ps for all six, plus eight further KARTES sources (timeouts
and ineligibility reported). More parameter plans do not create more mechanisms.
Fresh heldouts are raw/exact screens only unless an explicit paid receipt says
otherwise. No native trial or external reviewer is represented by these tests.

## Why KARTES is distinguishable, and why novelty is still bounded

KLADOS maintains a self-adjusting BST as a word dictionary. KARTES builds a
static minimum Cartesian tree over source positions. PINAKAS emits insertion and
recording tableaux; KARTES uses child flags and preorder labels. STOIBAS traverses
a JSON parse tree, not a priority-induced tree over arbitrary literal fields.
DENDRONS's phrase "Cartesian factoring" denotes factoring brace-product tails,
not Cartesian trees. MONODROMOS solves transition-multiset uniqueness; KARTES
pays explicit shape. LEXARITHMOS, KRYPTOLYSIS, DEIKTIS, SYMFRAZ, KYKLOS, METRIDA
and FOTIA use respectively numeral rules, alphabet shifts, history pointers,
context sorting, dictionary cursors, constrained assignments and word rotations.
These comparisons and source grep across429 modules are bounded triage, not a
semantic novelty proof against every composition of the complete stack.

Classical Cartesian-tree serialization is prior art. The repository addition is
a readable paid preconditioner experiment, not an AI-only invention or a claim
that the underlying idea was absent from training. Acceptance remains withheld
without utility and native gates, even if the implementation is locally distinct.
