# E–G. Mechanism portfolio and adversary

Actual artifacts: `portfolio.ts`, `test.ts`, `adversary.ts`, `receipts/screen.json`. Six distinct operations were executed on37 actual repository sources. Only DESMI is newly implemented. These are six program paths, not six independent agents or Git branches. Early independent research by multiple agents was not available.

The TS adversary tests malformed candidates and contract omissions. The Python DESMI reader independently reimplements intervals and references without importing the encoder. It is not independent personnel. Actual generated test inputs exercise code; they are not simulated model outputs. No mocked performance or native trials are reported.

## D. Eighteen false solution shapes
1. Raw-source savings called parent savings.
2. Character overlap called token saving.
3. Free reservoir.
4. Free interval table.
5. Free instruction key.
6. Parent cost omitted.
7. Set of words recovered but source order lost.
8. Unicode codepoints confused with UTF16 offsets.
9. Recursive substitution where the contract says once.
10. A source read from disk by the supposed native decoder.
11. Program inverse called basic-chat evidence.
12. Single niche win called broad gain.
13. Censored timeout called win or measured loss.
14. Unsupported parent envelope called byte-exact.
15. Candidate count called independent-agent count.
16. Classical superstring approximation transferred to paid BPE.
17. Microbenchmark improvement called whole-stack speed.
18. Merge or compilation called research acceptance.

Modal shortcut detector: `diagnostic.ts` identifies actual plans whose full standalone wire beats raw input but remains above the existing parent. It asserts that such counterexamples exist, then marks body-only ablations noninvertible. Its two counterexamples must never be scored as frontier wins.

## I. Repair rule
No codec grammar repair after tests. Added boundary/no-rescan positive probes received a fresh entire TS run and independent Python run. Any future grammar change must rerun both plus a patch-specific attack. Speed build changes require fresh count/vector/merge/threshold checks and full-stack measurements. No inherited result establishes a repaired candidate.
