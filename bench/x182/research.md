## Stack novelty boundary

Focused source search for Sparre/deque/prefix-sum-sign mechanisms found no prior
implementation (receipt novelty-search.log). This is lexical triage, not an
all-stack semantic proof. ROPI has no comparison-delimited rotations (FOTIA),
suffix rotation sort/LF cycles (KYKLOGRAF), recording tableau (PINAKAS), adaptive
BST paths (KLADOS), omission rules (APOUSIA), successor queues (DIADOCHI), Euler
uniqueness solver (MONODROMOS), JSON BFS queue (STOIBAS), numeral grammar
(LEXARITHMOS), alphabet rotation (KRYPTOLYSIS), suffix pointer (DEIKTIS), frozen
context collation (SYMFRAZ), marker-cycle cursor (KYKLOS), or length-sum alternative
assignment (METRIDA). The last comparison is especially important: ROPI's sum
selects a deque END, not a replacement assignment, and every field stays literal.
These distinctions do not establish novelty against every possible composition.

### OpenAI
Followed EncodingBounds into BinaryArithmetic. `toNat` is explicitly
little-endian; sumBit/carryBit define a Boolean full adder with an eight-case
proof. Empty and zero-containing lists need not be canonical encodings, so
countWord's separate canonical representation matters. Correct arithmetic does
not establish the counting-program existence absent from Statement, nor a
practical optimizer for this repository's token objective.

### Anthropic formal-math
Followed SolverPoly's RunFor premise into RunFor. `cutAt_some` requires
7*S+2≤room and state size≤S; halted-state persistence also retains these bounds.
This narrows the resource interface. A polynomial step machine with insufficient
room/fuel cannot silently be replaced by an unbounded successful solver.

### Anthropic FLT
Revisited the pinned proof path and irreducibility definition: nontrivial torsion
and no nontrivial Galois-stable submodule, over the specified scalar/actions.
No further FLT import graph was compiled. A definition check is not proof replay.

### DoubleAI
Followed All63/Enc into Circuit. Wire has explicit true/false/literal variants;
Ex.evalAll([])=true and Ex.evalAny([])=false. Formula evaluation is not a proof
that the CNF encoder preserves legal chess positions or that all certificates
are unsatisfiable. The 7,224 certificate cases and a reachable 63-move witness
remain separate unexecuted obligations; no codec consequence is imported.

### Google DeepMind
Followed the positive-density dependency into Data/Set/Interval. Fintype

are not an efficient enumerator for arbitrary sparse sets or a compression bound.
The positive limiting-density versus limsup distinction remains material.

## Achievability/impossibility interface

The proved construction-level invariant supplies an executable inverse, and
finite independent checks support the implementation. Counting bounds forbid
universal compression of all fixed-length strings below capacity, not better
codes on practical distributions. Between these lies the unclosed interface:
complete paid BPE savings, runtime, meaningful source breadth and actual native
basic-chat execution. Neither the latest mathematical publicity nor a reversible
permutation closes it. Best-known global/native optimality was not established.
