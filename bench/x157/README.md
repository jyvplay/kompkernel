## A–G formal model, information, resources and quantifiers

Sources: UTF8-stable strings <=50000 UTF16 units. Eligible sources contain
Git unified diffs with canonical nonnegative decimal hunk coordinates <=999999999,
count1 omitted, and well-formed signed bodies. Within a hunk, context lines count
on both sides, '-' only old, '+' only new; exact backslash no-newline notes count
on neither. Other bytes are copied. File boundaries reset a signed balance.

Wire operation: `@A@` replaces the full hunk-header prefix, retaining its suffix.
From following body records derive O,N; reconstruct new start B=A+D+[O=0]-[N=0],
where D is prior new-minus-old line count in this file. Emit canonical
`@@ -A,O +B,N @@`, omitting ,1, then set D:=D+N-O. Zero-count positions need the
explicit +/-1 correction; without it insertions/deletions are wrong. This is a
cross-hunk conservation law, not value normalization or reconstructing file
contents from a patch. No external preimage is available or required.

Admission: whole source equality after inverse, no mismatched counts, noncanonical
numeric spelling or ambiguous @ lines. Invalid UTF16 and oversized expansions
refuse. CR bytes in body lines survive; unsupported header layouts refuse rather
than normalize. This is a bounded string codec, not arbitrary invalid-byte coding.

Encoder knows the source, fixed tokenizer and full X156 incumbent pipeline.
The intended native decoder gets ONE complete message including the instructions
and parent representation, with no system prompt, skills file, tools, reference
source, training or custom vocabulary. A Python/TS inverse is a different verifier
and never certifies native LLM performance. No native endpoint is available.

Metrics: exact full-message o200k_base tokens, exact disk-source UTF8 bytes,
encoder wall/CPU/memory, and native behavior. Header and parent are charged.
Source transforms and extra parent searches are not free. Zero byte/count tolerance.
Cost selection is `forall admitted source x, min(cost(base(x)), cost(valid C(x)))`;
a >10-token measured win on one source is existential, not universal superiority.
Native success requires fixing a model/protocol BEFORE blind exact-output tests;
no uncalled model can satisfy it. All production defaults remain untouched.

Comparator: SYNECHEIA's incumbent, including STOIBAS/ARKESIS/KENOMA/HOMOSEMA and
TAGSTACK. This does not claim every unwired historical experiment is executed.
Flags: OMEGA_DET=1, OMEGA_NO_MEMO=1, OMEGA_ENGRAM=0, OMEGA_OURA_MEMO=0,
OMEGA_NO_OROTHESIA=1. Canonical rerun uses the established29-lane runner; prior
external gains are revalidation targets, not silently relabeled fresh searches.

Adjacent problems excluded: applying a patch, semantic code equality, normalized
patches, shortened display context, binary diff compression, payload-only pricing,
weaker parent comparisons, code-point rather than byte equality, trained model
arithmetic coding, changed vocabulary, grammar-size bounds as token bounds,
source inspection as kernel replay, and model task accuracy as exact reconstruction.

## Construction, proof boundary and costs

Induct on hunks within one file. Body prefixes uniquely determine O,N within the
admitted framing. Prior balance D equals the net number of prior inserted lines.
The correction for empty ranges matches Git's zero-length coordinate convention.
Thus B is determined. Canonical header rendering and copied suffix/body recover
the exact original header/body. File reset establishes the induction base.
Entire inverse comparison is a separate executable check, not just this argument.

Novelty is bounded. X51 already screened count elision; count elision alone is NOT
new. This implementation adds cumulative new-start reconstruction, empty-range
corrections, framing and a full-stack selector. It is classical format entailment,
not a new mathematical compression primitive or exclusively AI-native discovery.
Research.md records inspected stack ancestry, live references and missing audits.

Greedy: no transform search; one deterministic admitted pass. Selector compares
one candidate with the incumbent, not a globally optimal codec. O(n) work/space,
CPU/work bounded, not time-budget-selected. Coordinates and balance remain exactly
representable JS integers under declared caps. Full parent dominates, and adds
work. A1800s experimental timeout or heap failure is NOT a negative token count
or a verification pass. Cases exceeding budget remain inconclusive.
