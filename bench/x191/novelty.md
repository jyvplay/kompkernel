# Novelty audit: narrow distinction, no all-stack certificate

437 TypeScript module headers and file hashes are inventoried in
`receipts/module-inventory.json`. Header/keyword inspection is not exhaustive
semantic equivalence checking. DIEXODOS is a new implementation, but no claim
that it is a new mathematical primitive or wholly absent from the expressive
power of every codec is accepted.

| Existing mechanism | Comparison with DIEXODOS |
|---|---|
| MONODROMOS | Uses every edge exactly its paid multiplicity; DIEXODOS reusable relation + fixed length + two surviving endpoints. Closest graph ancestry. |
| APOUSIA | Causal deterministic next-field prediction; right endpoint can resolve actual branching in DIEXODOS. |
| DIADOCHI | Ordered FIFO successors paid in queues; DIEXODOS has no queue order or consumption inventory. |
| METRIDA | Unique assignment under a length-sum constraint; same broad constrained-decoding ancestry, different constraint and unit. No claim to invent constraint decoding. |
| STOIBAS | Breadth-first JSON node/degree reconstruction, not arbitrary relation paths. |
| LEXARITHMOS | Fixed numeral grammar transduction, not graph witnesses. |
| KRYPTOLYSIS | Bijective alphabet substitution, not data-dependent erasure. |
| DEIKTIS | Last-output-context copy addresses, not noncausal bridge feasibility. |
| SYMFRAZ | Frozen-context numeric side-stream collation, not path uniqueness. |
| KYKLOS | Cyclic word schedules with counters, not relation-constrained gaps. |
| KLADOS | Adaptive binary-search-tree access paths and rotations; references name nodes, not inferred missing sequences. |
| FOTIA | Content-preserving block bijection, not an in-band graph relation. |
| DIPIGI | Two-parent prefix/middle/suffix dictionary entries, not sequence-level bridge constraints. |

General macro languages can express many of these operations indirectly. A
local operational distinction and absence of an identical keyword are not an
all-stack novelty theorem. The five portfolio probes have explicit classical
ancestry and are not advertised as new codecs. This stronger user acceptance
gate remains unfulfilled.
