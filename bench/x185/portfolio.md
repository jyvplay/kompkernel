Only PERAS is newly implemented here. Raw-screen results are not equivalent to paid parent trials or six independent research agents.

## Attacker roles, actually executed

One assistant authored encoder and TS tests; a separately implemented Python inverse reads serialized pairs and paid parents without importing the encoder. This is implementation separation, not independent personnel. Adversary cases target malformed endpoints, grammar collisions, expansion caps, Unicode, field empties and forward references. Threshold attacks target byte/UTF16 boundaries and exact token counts. A model-native receiver, external human reviewer, exhaustive semantic novelty audit and formal proof kernel were NOT_RUN.

Repair policy: a change to grammar/inverse requires fresh unit, independent reader and targeted malformed-wire gates. A tokenizer change requires fresh count/vector/merge/threshold and complete-stack wire comparisons. No inherited pass can substitute for the affected gate. No failed candidate is promoted.
