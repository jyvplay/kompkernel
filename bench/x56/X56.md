## §A Formal Model

Admissible objects: a delimited table (delimiter one of `,;`TAB;
LF or CRLF line endings; BOM tolerated as content of the first
field) whose lines form a rectangular field grid of arity A. One
square block is sought: parameters header ∈ {0,1}, label width
L ∈ {0,1}, trailing pad t ≥ 0 (the last t columns empty in every
line), block size n = lines − header with A − L − t = n,
6 ≤ n ≤ 500, total chars ≤ 400,000. The block cells must be
unquoted (raw field == value; quoting normalized cells are
refused outright in v1).

Success predicate (explicit quantifier order): for the emitted
message M = contract ⨁ parent(reduced), for every admissible
input T produced by the generator of §F and the real fixtures,
Restore(parent-decode(M)) == T byte-for-byte; and there exists a
real fixture T with tokens(M) < tokens(F(T)) where F is the full
in-encode measured TAGSTACK + SIBLING-TEMPLATE frontier,
strictly, both counted whole-message under o200k_base. Failure =
any byte mismatch, or no strict frontier win on any real lane.

Mechanism: verify string-exact transposition symmetry
cell[i][j] == cell[j][i] for all i<j in the block, allowing ≤6
exception pairs (and ≥95% symmetric pairs) whose lower cell ships
verbatim. Blank every non-exception strictly-lower-triangle
cell; if all diagonal cells are one identical non-empty string
(constant ≤24 chars, no quotes/braces), optionally blank the
diagonal too and state the constant once. The reader refills each
blank from its mirror across the diagonal — by row/column names
when header names equal the label column in order (checked), by
block coordinates otherwise. A blank on the diagonal mirrors to
itself (contract-sound; exercised by goal3's empty header corner).

Resource counted: whole-message o200k_base tokens (contract +
parent-coded wire). Regime: single chat message, stock reader,
no tools, no side channel.

Adjacent problems not substituted: symmetric-matrix *storage*
for numerical kernels (LAPACK UPLO packed formats — binary/typed,
not one-chat text); lossless CSV *byte* compressors (gzip-class,
not LLM-readable); lossy table summarization for LLM analysis
(SpreadsheetLLM-style tokenization); matrix *completion* (statistical
estimation of missing entries — not exact); graph adjacency-list
conversion (changes the artifact, loses byte identity).

## §D Negative space

Modal shortcut of the turn: **"APOGRAPHE's `col` predictor
already copies cells, and `above` already propagates — symmetry
is covered"**. Detector: read the predictor union
(`apographe.ts:185-199`): `above` (cell at (r−1,c)), `col` (cell
at (r,src) same line), `days/workdays` (date step), `int`
(above+b), `lin`/`clock` (function of row index). The mirror of
(r,c) is (c,r): a different row *and* a different column, with the
row distance |r−c| unbounded. No composition of one-step moves
exists (predictors read the reader's one-line state, not a stored
matrix). Failure test: run APOGRAPHE on a symmetric matrix —
§H measures it at 3,297 vs candidate 1,673 on us31: it squeezes
float format patterns but cannot touch the transpose redundancy.

Owned or dead, do not re-propose: (1) forward-fill / run columns
→ APOGRAPHE `above`; (2) index/linear columns → METRON
`lin/clock`; (3) periodic columns in *aligned* blocks → KANNABOS
`s%M`; (4) constant-sum share rows (`Σpct=100`) → KEPHALAION
headsum-adjacent (v2 family, §E.4); (5) full-grid crossings via
row-index arithmetic (METRON imports; KANNABOS aligned); (6)
rank columns on *sorted* tables → METRON `lin` (rank == row
index; see §E.3 for the unsorted case); (7) functional
code↔label dictionaries → SYLLOGISMOS `lookup`; (8) sparse COO
listing → zeros/empties price ~free under BPE+parents (X55
zero-slice measurement); (9) threshold-flag columns ("Yes/No") —
per-cell mass ~1 token, dead economics; (10) checksum digits
(Luhn/IBAN) — dead economics, prior turns; (11) date/weekday
columns → APOGRAPHE `days/workdays`, HEMERA; (12) interval
duration = end−start → SYLLOGISMOS binary; (13) string length /
affix / case derivatives → SYLLOGISMOS `split/case/concat`;
(14) calendar grids → tiny, prior verdict stands; (15) row-order
permutation with later re-sort — original order unrecoverable
without shipping it (self-defeating); (16) transpose-file
rewrites (ship the melt/pivot) — changes bytes, parents already
see both shapes equally.

## §E Mechanism portfolio (six, independent-first)

1. **Transposition symmetry — chosen.** Construction in §A.
   Artifact `src/lib/omega/isoskeles.ts` (registered
   `isoskeles`). Proved: restore correctness by construction
   (mirror involution; exceptions verbatim; whole-input byte
   check arbitrates). Unresolved: quoted cells refused; multiple
   disjoint square blocks not attempted. Cheapest falsification:
   APOGRAPHE on a real symmetric lane beating the candidate (§H:
   it does not).
2. **Periodic/crossed categorical columns in delimited tables**
   (tidy long-format: col cycles by row index mod p). Unowned by
   APOGRAPHE (no periodic family); KANNABOS owns the aligned
   version. Rejected as headline: cycling spans are exactly what
   dictionary parents price cheapest — residual predicted small
   by the X55 economics lesson; kept as next-turn candidate with
   a cheap falsification (DAE/APO on a crossed real lane). Local
   gap, not equivalent to the original.
3. **Rank columns on unsorted tables** (reader ranks the shipped
   value column). Unowned where order ≠ rank (sorted case is
   METRON). Rejected: 100+-float byte-exact sorting with tie
   conventions is the highest-risk reader obligation in this
   list, and rank columns are small integers parents already
   price low. Counterexample: any tie-heavy leaderboard breaks
   byte faithfulness under `competition` vs `dense` conventions
   unless the convention is corpus-fitted — doable but hazardous.
4. **Constant-head headsum for composition rows** (`Σpct = 100`,
   elide the residual category). Honest classification:
   KEPHALAION family extension, fails the brand-new-mechanism
   bar as a headline; recorded for a KEPHALAION v2. Gap is local
   (share tables whose printed values sum exactly may be rarer
   than believed — rounding to 99.9/100.1 common; falsifiable by
   a 1-hour corpus scan).
5. **Antisymmetric / skew blocks** (cell[j][i] = −cell[i][j];
   net-flow, difference matrices). Genuinely adjacent to (1) —
   one sign bit of extra contract. Deferred: no real lane in
   hand this turn; cheap to add to ISOSKELES later; red team
   includes an antisymmetric refusal case.
6. **Block-diagonal / repeated-block structure** (same submatrix
   repeated k times — panel data). Overlaps template parents
   (SIBLING-TEMPLATE exists precisely for repeated blocks);
   residual unclear; deprioritized.

## §G Second-order adversary

- **Near-symmetry masquerade**: a table 94% symmetric by chance
  (coarse values, e.g. 0/1 adjacency of a directed graph that
  happens to be mostly reciprocal). Guards: ≤6 exception pairs
  AND ≥95% symmetric AND whole-restore byte check — worst case
  it still round-trips exactly; the only failure is a missed
  economy, gated by frontier measurement.
- **Rounding twins** (`0.5` vs `0.50`): string-asymmetric pairs
  consume the exception budget; >6 pairs → the whole shape is
  refused rather than normalized (normalizing would break bytes).
- **Header-shaped trap**: a 32×32 "symmetry" found across
  semantically unrelated label/header strings — restore still
  arbitrates byte-exactness; reader contract stays precise
  (positional form).
- **Ambiguous blanks**: original empty cells inside the block —
  blanks-on-diagonal mirror to themselves (goal3 corner);
  off-diagonal original empties mirror to the (also-empty, by
  string symmetry) partner. Quoted cells refused.
- **Reader risk profile**: copying is the mildest obligation in
  the family; the named form ("row named by its column") needs
  name matching, the positional form needs counting. Both
  blind-decoded (§H). A slip damages exactly one cell (no
  propagation, no accumulation).
- **Cost-model adversary**: plan ranking uses raw tokens of
  contract+reduced; the header-subsuming shape beat the named
  shape on both distance lanes pre-parent and also won
  post-parent (§H: candidate boarded on APOGRAPHE-reduced).
