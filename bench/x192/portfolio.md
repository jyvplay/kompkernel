# Six mechanism-distinct approaches

These are experiments, not six novel inventions or six successful native codecs. All begin with original source, not lossy preprocessed text. The five classical controls reuse the X191 harness, rerun on the 39-source screen; 217 checks and 187 emitted messages. MARTYS has its own TS and separate Python artifacts. Control messages pay explanatory keys but have not been passed through parent or native decoders this turn. They cannot be promoted to frontier winners from raw cost alone.

| Approach / construction | Executed artifact | Established portion | Unresolved interface | Cheapest falsification / gap |
|---|---|---|---|---|
| Literal-witness substring addressing (MARTYS) | `test.ts`, `independent.py`, paid worker receipts | Literal set invariant, deterministic one-pass substitution after witness discovery; finite malformed/round-trip tests | Native basic-chat exactness and all-stack novelty | Forward and ambiguous fragments, paid parent comparison; behavioral/novelty gap |
| Factoradic permutation rank over sorted 8-field blocks | `portfolio.py`, family `rank` | Rank retains ordering including duplicates via index tie-break | Model unranking, overhead | Remove rank: `a b`/`b a` collide; representation-cost gap |
| Single-erasure scalar checksum per 16-scalar block | same, `checksum` | Missing final scalar equals sum minus prefix sum | Model arithmetic and token cost | Two erasures `ab`/`ba` collide; information gap if generalized |
| Signed differences of decimal runs plus explicit widths | same, `delta` | Prefix sums recover values, widths recover leading zeros | Parent interaction and arithmetic behavior | `000 999 001`, width omission attack; format/behavior gap |
| Backward field-distance copy | same, `distance` | Induction on positions with strictly backward distances | Existing copy-codec ancestry and native off-by-one risk | Reject distance 1 at empty history; novelty/behavior gap |
| Even/odd scalar layout | same, `parity` | Interleave restores every Unicode scalar and separator | BPE benefit, parent reconstruction, model ordering | Emoji, CRLF, odd-length input; cost/behavior gap |

These differ in mathematical inversion: unique set lookup, permutation unranking, linear equation, cumulative sum, causal copying, and fixed index permutation. Common JSON packaging is not counted as a distinct mechanism. Portfolio finite checks prove neither optimality nor general model reliability. No external verifier was invoked; Python independence means separate implementation, not separate personnel.
