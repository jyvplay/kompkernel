## A–G: precise model

Admissible sources are UTF8-stable strings <=50,000 UTF16 units. The transform
recognizes lowercase hexadecimal `start-end ` at LF-delimited line starts, both
12..16 digits, canonical minimum12-digit padding, page-aligned endpoints,
0<=start<end<2^64. Other bytes remain verbatim, including spacing, paths, CRLF,
Unicode, and missing final LF. Any source with a reserved @ line start refuses.
Source files are captured literally, not normalized or generated to win.

A transformed record is `@HEX+N` for an explicit start, or `@N` if its start
matches the previous TRANSFORMED record's end. N is a positive decimal count of
4096-byte pages. Literal lines do not update recurrence state. Decoder expands
start/end to the canonical source hex spelling. Invalid inputs, output-cap
violations and UTF8-unstable strings refuse; no JS floating-point arithmetic is
used on addresses. The original absolute reset addresses are never discarded.

Encoder information: full source, fixed tokenizer, all existing incumbent
modules, and exact candidate readers. Decoder information: only one complete
message with an in-band instruction and self-contained parent, no source, tools,
skills, system prompt, pretrained custom symbols, model training or external
reference files. The Python and TS programs verify invertibility, not compliance
of a basic-chat LLM with this information model. Native gate: NOT_RUN.

Resource vector: exact complete o200k_base token count, UTF8 source equality,
encoder CPU/wall/memory, and behavioral exact-output success. Parent payload,
instruction, reset addresses and counts are all charged. Experimental discovery
and baseline search are not free. An added parent call cannot be described as a
runtime improvement because its candidate encoding alone happened to be fast.

Quantifiers: for every source in the API's verified-incumbent domain, compare a
fully verified candidate with its same-source incumbent and return the smaller
complete message, otherwise retain the incumbent. This establishes token
nonregression by construction, conditional on the actual readers. Separately,
there exists a measured real source with gain114>10. Neither implies that there
exists one codec improving every source, metric, or model. For native behavior,
first fix model/version/protocol, then run blind exact-byte trials over a declared
corpus; no result from an uncalled model is available.

The comparator is STOIBAS's full incumbent chain (TAGSTACK/HOMOSEMA/KENOMA/
ARKESIS/STOIBAS), not raw data. This does not mean all393 omega files, including
unwired negative experiments, are each re-executed as competing encoders.
Canonical flags: OMEGA_DET=1, OMEGA_NO_MEMO=1, OMEGA_ENGRAM=0,
OMEGA_OURA_MEMO=0, OMEGA_NO_OROTHESIA=1. Counts have zero tolerance, bytes zero
mismatch. Isolated speed threshold remains >=10% aggregate CPU AND wall reduction,
no protected-lane regression, all12 cold ABBA wires identical. No timing of
concurrent frontier runs can pass that gate.

Adjacent problems excluded: memory-map semantic equality, relocating addresses,

## H+, H−, H-boundary

H+: bounded token advantage. Accept after >10 tokens, full strong comparator,
reference tokenizer, disk-byte independent reader, transport and adversarial gates.
H+: full Pareto target. Requires the preceding gates PLUS native and runtime gates
and the requested useful breadth. Currently unsupported.
H−: universal shortening of all finite sources cannot hold for injective codes:
with V token symbols, at most sum(i=0..t)V^i strings fit into <=t tokens. This does
not prove useful structured-source improvements impossible. No impossibility of
the user's practical research target has been proved.
H-boundary: small maps fail to amortize instructions; arbitrary unaligned/case-
variant ranges refuse; one heldout map saves only3. General prose gets no new
plan on the canonical screens. Those are restrictions, not renamed successes.

## Construction, novelty and cost

Inductive invariant: before each encoded record the decoder's previous-end
register equals the encoder's. An explicit record sets start directly; an implicit
record's admitted equality supplies start. Exact multiplication/addition yields
end. Fixed rendering reconstructs the removed lexical range; the untouched suffix
and separators preserve all remaining bytes. The encoder checks the entire
inverse before pricing and checks the complete parent-composed inverse afterward.
No hash alone is accepted as byte equality.

This is classical prediction/delta ancestry, NOT a newly discovered mathematical
primitive or an AI-exclusive insight. Repository audit searched previous-end,
page4096, memory maps, intervals, hexadecimal addresses; inspected DIASTEMA,
KANNABOS, COLUMN, SCALAR and prior design entries. Distinction from DIASTEMA:
not independent decimal fields under a mask; the next record consumes the END
computed from the preceding record's START and LENGTH, while gaps carry absolute
reset values. Distinction from METRON: no constant arithmetic progression needs
to fit. No assertion of semantic nonequivalence to every possible stack composition.

No greedy search inside the transform: one deterministic eligible-record pass.
Final candidate selection is exact comparison over incumbent and one candidate,
not global codec optimization. CPU/work bounded, not time-cutoff selected: O(n)
character work and O(n) space with fixed64-bit bounded BigInt values. Parent cost
is additional and dominates. The experiment runner has a1200s timeout; timeout
means no measurement, never a passing result.
