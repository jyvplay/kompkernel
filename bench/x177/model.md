## Formal model

Admissible sources: ASCII byte strings of length ≤50,000; space-separated fields retain empty strings. Blocks are consecutive groups of 32, 128 or 512 fields, only the last shorter. Within a block, two candidate total orders sort by increasing/decreasing frequency, breaking ties by ASCII text. Since BBWT permutes fields, encoder and decoder see the identical histogram. The new entry point is **a BBWT variant**, not a claim to satisfy the requested distinct-mechanism novelty gate.

Resource T is reference o200k tokens in the **complete** inverse contract plus complete parent wire. Source equality means bytes from the original file, not semantic equivalence or encoder self-report. CPU and wall milliseconds, extra parent calls, memory, coverage and native behavior are separate dimensions. The tournament pays for every parent call; identical folded bodies may reuse one parent result within the same call only.

Executable goal: for every admitted x, V(E(x))=x. Structural justification: both ends derive the same total order from the invariant multiset; BBWT is a bijection for that fixed order; independent fixed-size blocks preserve the original field count and joining by ASCII spaces preserves all bytes. Tests bind implementations to this argument but are not a theorem-kernel proof.

Behavioral goal: there exists one fixed codec/contract such that, for every declared heldout setting and source x, a specified frozen native model M on a single fresh user message emits exactly x. The decoder gets no external dictionaries, tool, system prompt, skill file, prior source, retraining or special embedding access. Existence of V does not establish behavior of M. No adequate native endpoint is available here.

H+: byte gates, complete pricing, >10-token gains across multiple materially different ordinary prose/ops sources including heldouts, no protected regressions, and native verification all pass; significant whole-stack speed additionally requires CPU and wall B/A≤0.90 and each protected lane≤1.00 in isolated ABBA runs. No claim before all corresponding gates pass.

H−: injectivity rules out fitting |Σ|^n distinct sources into fewer than |Σ|^n available codewords. If Σ(i=0..k)|Vocab|^i<|Σ|^n, a ≤k-token universal bound is impossible. This does not imply Brotli or the current frontier is optimal. Candidate losses refute candidate-specific wins, not the existence of a future codec.

H∂: source domain, block size, alphabet order, tokenizer, decoder access, cold/warm process state and statistical distribution can change outcomes. Missing native evidence and unestablished novelty stay explicit.
