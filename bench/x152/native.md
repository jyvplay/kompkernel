# Independent one-basic-chat gate — NOT_RUN

The candidate with the strongest measured token gain is the VS Code JSON manifest
wire saved as `receipts/native-packet.txt` when final gates run. It is a complete
single-message payload: recursive grammar key plus JSON closer restoration key.
Do not supply the original file, skills.md, a system prompt, a decoder program,
examples, hints or repair instructions to the model.

Protocol:
1. Open a fresh ordinary chat and paste only `native-packet.txt` verbatim.
2. Record model/product/version, timestamp and exactly one unedited response.
3. Export response text without stripping fences or normalizing line endings.
4. Compare UTF-8 bytes to `fixtures/vscode-json-package.json`; report first differing
   offset and byte lengths. A parser accepting the same JSON value is not enough.
5. Record refusals, incomplete output, added prose and formatting changes as failures.
   A repaired instruction starts a new candidate and inherits no previous success.

The expected source hash is recorded in `receipts/fused.jsonl` and `provenance.json`.
The original is withheld from the actual model prompt, not hidden from the operator.
Python's successful independent reconstruction does not fill this gate. No native
model API or independent chat agent was exposed in this session. Neither my
in-context explanation nor a tiny hand-readable example is a blind evaluation.
One success would certify only that particular trial, not reliable universal
native decoding. Broader deployment needs preregistered unseen cases and failures.
