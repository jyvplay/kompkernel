## A. Formal model

**Source.** An admissible source is a finite UTF-8 byte string `x`; exactness means byte-for-byte reconstruction, including whitespace, code points, line endings, and final-newline state. ALPHAFOLD is restricted to text containing repeated balanced-brace blocks that match lexically after identifier-slot normalization. It refuses a source without a collision-free marker set, with unterminated string/comment, beyond 200,000 UTF-16 code units, or without a profitable repeated alpha-pattern.

**Access.** The decoder receives exactly one basic chat message, containing the parent decoder, the complete ALPHAFOLD instruction, the template(s), instance bindings, and remaining body. No `skills.md`, hidden prompt, system instruction, external codebook, parser library, source file, retrieval, or out-of-band state is required by the declared decoder rule. The encoder uses a local conservative lexical scanner; this is not on the decoder path. The contract is an explicit algorithm; whether a general LLM executes it byte-exactly has not been tested.

**Resource.** `T(m) = countTokens(m, o200k_base)` of the *entire message*, including all parent and ALPHAFOLD contracts, template text, binding names, and payload. Comparator is the complete same-source TAGSTACK runtime-parent plus SIBLING-TEMPLATE frontier, not the registry-wide set. Wall-clock time is separately reported, not substituted for token cost.

**Success predicate.** A candidate succeeds on `x` only if its in-band expansion equals `x` byte-for-byte, both complete source and candidate frontiers finished, and complete candidate tokens are strictly fewer than the complete same-source frontier. A practical gain threshold for this turn is ≥10 tokens on an authentic lane; a corpus Pareto claim additionally needs no regression on a frozen held-out set. Native-LM success would require an actual model to reconstruct the bytes from the single emitted message; not measured.

**Quantifiers.** A local existence result is `∃ C ∃ x∈L : D_C(E_C(x))=x ∧ T(E_C(x)) < F(x)`, with source lane `L` named and hashed. A corpus Pareto claim is `∀x∈H, exact(x) ∧ T(E_C(x))≤F(x)` and `∃x∈H, T(E_C(x))≤F(x)-10` on a frozen held-out set `H`. X63 established exact transform/decoder behavior on a code fixture but **did not establish the local strict-cost inequality**, much less the corpus predicate.

**Boundary and units.** Token count uses `o200k_base`; source length cap is UTF-16 code units; expansion relation is UTF-8 byte equality. The parent frontier is six measured arms recorded in the receipt and SIBLING-TEMPLATE, `OMEGA_DET` unset, Node v22.22.3. The learned-template parser is deliberately lexical and capped; dynamic code semantics and AST interpretation are not required to restore the original source. This does not establish compression of source programs under compilation semantics.

**Not substitutes:** lossy code summarization, generated code from a model, semantic clone detection, binary/Huffman/Zstd compression with an external decoder, BWT/MTF scrambled payloads, out-of-band AST/codebook, tokenizer retraining, model fine-tuning, near-duplicate fuzzy matching, raw payload-only savings, a candidate/member comparison, or a single exact library decoder mistaken for a native LLM trial.

## C. Mechanism: ALPHAFOLD lexical alpha-template folding

`src/lib/omega/alphafold.ts` registers `alphafold` in the Omega registry. It lexes whitespace, identifiers, punctuation, strings/templates, and comments. In balanced brace spans of 80–10,000 chars, each non-keyword identifier is temporarily assigned a first-occurrence slot. Blocks with identical lexical structure and at least one *varying* identifier position are grouped. Across a group, identifier positions shared by all instances remain literal in the template; only differing names are sent in comma-separated binding lists. A template section and each instance reference are carried in the same message. The decoder fills its numbered slots and substitutes references; exact expansion is mandatory before scoring. Marker collision selects a second/third in-band marker set, or refuses if all pools occur. The encoder is deterministic, no greedy search over token strings; template groups are ordered by estimated char saving with non-overlap, and only the live complete-frontier gate can emit.

The block equivalence is lexical, not a claim of full AST alpha-equivalence: no parse tree, scoping theorem, or semantic clone claim is needed because exact inverse is checked. String/comment/template-literal bodies are opaque; unsupported edge syntax is either kept literal or refused. The algorithm's only proven property is the tested source-to-wire-to-source text equality, not code behavior under execution.

### Falsification and second-order attacks

Red-team cases attack: identifier order changes; repeated use of one binding; constant identifier positions; quoted text containing braces/names; CRLF and no final newline; a source marker collision and alternate marker selection; collision with every marker pool; exact duplicate blocks with no renamed identifiers; one-block/no-block/prose false positives; malformed mapping; incomplete/unfilled slots; overlong payload; mismatched group counts; marker injection in a binding; nested/overlapping brace spans; comments with braces; template strings with `${}`; regex literals and Unicode identifiers. Implemented tests cover the first 11 named cases including 34 references in the real repository file; scanner caps, exact inverse and parser reject malformed lists. Regex literal and full Unicode-identifier parser coverage remain explicit limits, not established as tested. The 13 TS tests additionally reject unused surplus bindings and a <1-MiB wire whose repeated template would exceed the 1,000,000-character expansion cap. The independent Python twin reconstructs six valid vectors including the alternate marker set, but it is still a separately written local decoder, not an external LLM.

**Modal shortcut test:** “same code structure modulo identifiers” is not enough to omit names from the binding list; `const a=x` and `const a=y` differ in decoded bytes even if execution is analogous. The current code preserves every varying identifier spelling and directly asserts reconstructed source equality. This rejects semantic/alpha-equivalence as a substitute for exact restoration.

## D. Negative space / false wins

1. 7,503 wire characters vs 10,538 source chars is not the token objective.
2. 2,464 raw wire tokens vs 3,097 source tokens is not the complete parent message.
3. Full candidate 1,249 vs frontier 1,114 is a measured loss, not “almost a win.”
4. A candidate-parent member win would not suffice without complete source and candidate frontiers.
5. Leaving common identifiers in the template can silently corrupt renamed code; only invariant slots may be hoisted.
6. Replacing every identifier regardless of lexical status can alter quoted code/examples; strings/comments are opaque.
7. Treating comments as semantically ignorable is lossy for source text; comments remain in literal template bytes.
8. Collapsing CRLF/LF as equivalent is not byte-exact; test preserves CRLF.
9. Assuming all `}` characters are block endings fails on strings/comments; lexical scan skips them.
10. Assuming a code parser/AST is available to the decoder violates the one-message contract; decoder uses in-band literal substitution only.
11. Claiming full AST alpha-equivalence is unsupported; this is a lexical block transform.
12. Claiming semantic equivalence of two blocks is unnecessary and unproved.
13. Inserting wire markers already present in the source can make the inverse ambiguous; marker pool is absent-check/refusal tested.
14. A malformed `⟦n|map⟧` must fail, not partially expand; malformed identifiers are rejected.
15. Treating `\u2000` Unicode identifiers as ASCII identifier tokens is unsupported; they are left literal and may prevent grouping.
16. Counting `a,b` as a map without a safe name grammar permits delimiter injection; map entries are constrained to identifier spelling.
17. A block group with only exact duplicate names is a generic copy/dictionary case and is refused as non-alpha gain.
18. Pairwise similarity or Type-3 clone detection is not this exact transform; only exact canonical token sequence match is admitted.
19. A codec contract that says “rename equivalents” without carrying every changed spelling is ambiguous and lossy.
20. An assumed native LLM decode from the 11/11 TS checks is unsupported; no LLM test was made.
21. A proof paper's abstract claim or code-clone benchmark is not evidence that this codec beats a live tokenizer parent.
