# Six executable mechanism families, with ancestry and falsifiers

All six families execute separately from the same parent and seed pool. No
family receives another family's winning wire. They are distinct *move
mechanisms*, not six established new primitives. Their shared grammar and seed
selection limit independence. Initial character-ranked exploration preceded
explicit token/boundary ablations; the final rerun is regression confirmation,
not a blinded discovery test. Each concrete artifact is the named family in
`anaplasisTrial`, a row per source in `receipts/trials.jsonl`, and generated
source/inverse cases in `unit.json`.

| Family | Construction / structural lemma | Established portion | Unresolved interface | Cheap structural attacker | Gap |
|---|---|---|---|---|---|
| delete | Inline one/two rules later-first, leaving dependencies intact | Exact returned source and paid cost tested | Does removal alone beat mature grammar? | A shared nested rule whose removal expands every user | Local search quality; overlaps DIAGRAPHE/SYNAIRESIS |
| remine | Keep uphill deletion; append a repeated exposed body span as a new rule | Final exact reader and whole-message pricing | Can replacement repay deletion, instruction and definition? | Overlapping `aaaa`, split surrogate, rare long phrase ranked ahead of valuable short phrase | Local bounded candidate coverage; substantial SYNARMOGE ancestry |
| factor | Place a shared span after its dependencies and before rewritten later rules | Dependency location explicit, final inverse gate | Can jointly changing tape and body expose broad paid savings? | Span referencing a later rule, operator-prefixed span, early-use cycle | Local placement/search; related to EUROS and tape factoring |
| rename | After deletion replace all occurrences of one name with a fresh same-script name | Fresh-name and literal-collision checks; exact return | BPE boundary gains may not repay deletion | Name already present literally in source; mixed scripts | Local search; METONOMASIA/METATHESIS ancestry |
| reorder | Move a definition only if all dependencies remain earlier | Dependency check before emission; source gate | Whether a different tape order crosses BPE boundaries profitably | Nested dependency chain with only one legal order | Local enumeration; METATAXIS ancestry |
| alias | Append an alias; change only body occurrences following one of four contexts | Same expanded value at selected occurrences | Context-specific alias gain versus extra definition cost | Different preceding whitespace, alias output captured by another rule | Local search; ALLOMORPH ancestry |

The core proposed extension is **joint evaluation across a costly deletion**,
not deletion, aliasing, reordering, or remining themselves. SYNARMOGE's sequential
`tryMove` rejects non-improving intermediate states; ANAPLASIS retains some.
That is a checked implementation difference, not proof that no other codec
implements the same semantic search. The module inventory hashes all omega
TypeScript files; headers and keyword matches are insufficient for all-stack
novelty. ANANKE and VELTISTOS already use bounded beam-style grammar/parse work;
X126 already investigated annealed assignments. All-stack novelty remains open.

The named requested predecessors MONODROMOS, STOIBAS, LEXARITHMOS, KRYPTOLYSIS,
DEIKTIS, SYMFRAZ, KYKLOS, METRIDA, KLADOS and FOTIA are not assumed irrelevant.
A full semantic non-equivalence audit of those and the rest of the stack has
not been proved. No borrowed paper theorem supplies such a result.

Every family has a concrete executable artifact and falsification path, but
none bypasses the original native-reader and broad-gain problem. A local
correctness argument about inlining cannot resolve that global interface.
