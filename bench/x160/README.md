# X160 — HAPLOGRAPHE / exact Git envelope recordization

## A. Formal model and access

Source x is a UTF8-stable string, at most50,000 UTF16 code units. Semantic
normalization is forbidden. D(E(x)) must equal original file bytes. Price is
reference o200k_base encode length of the ENTIRE message, including every
instruction and parent. No tokenizer training, private vocabulary, skills,
system prompt or external dictionary is available to the intended reader.
Software read callbacks are explicitly not evidence about native model behavior.
Access: local code, npm tokenizer, public GitHub/web sources; no independent
model endpoint or Lean executable. Quantifiers: tests are finite statements on
listed sources, not all prose or all strings. Universal strict shortening is
excluded by finite-alphabet counting, not used to rule out selected-family wins.

## B. Hypotheses / falsifiers

H+: a preregistered complete source saves >10 full tokens versus the operational
optional frontier through KLIMAX, has source-byte inverse, and (for the stronger
Pareto claim) blind basic-chat reconstruction and runtime non-regression.
H−: token loss/tie, source mismatch, malformed acceptance, or protected-lane
regression falsifies the respective component. H∂: bounded software-exact token
win without native/runtime evidence; NOT a Pareto certificate. Speed threshold:
>=10% lower aggregate CPU AND process wall, no per-lane regression, identical
wires;12 cold ABBA calls on3 fixed lanes, after competing encoders exit.

## C. New representation and novelty boundary

`src/lib/omega/haplographe.ts` replaces an exact canonical four-line modified
Git header by `!diff P H M`: the path appears once, hash pair once, mode once.
The full natural-language inverse is in-band. ASCII unquoted paths, lowercase
4–64digit hash halves, six octal mode digits, LF only. Renames, adds/deletes,
quoted/non-ASCII paths and collisions are not transformed. Other text stays
unchanged; final newline is preserved. A marker collision rejects the plan.
Expansion is bounded. Optional selection checks the incumbent inverse, verifies
candidate inverse, and strictly prices before accepting; ties keep incumbent.

Distinct from ISOSTATHMIA (hunk count equations), KLIMAX (ordinal successor
state), STOIBAS (indentation tree paths), ENTHYMEME (JVM filename entailment),
SYNDESMOS (URL roles), and generic dictionaries (paid aliases). This is classical
format/template coding applied to the actual repository interface, not a claim
of historical algorithmic novelty. Not wired into production/default encoding.

Proof sketch: each accepted source block matches equal path captures and exact
index/old/new role lines. Its record parses to those same captures; substitution
returns the block. Collision refusal makes new record lines disjoint from
untouched lines. Split/join preserves every LF and other character. Induction
over consumed lines gives the source identity on admitted input. Tests, not a
machine-checked universal proof, exercise implementation correspondence.
