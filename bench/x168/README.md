## D. New mechanism, construction and inverse proof

`src/lib/omega/diadochi.ts`: DIADOCHI (succession), **predecessor-routed FIFO streams**. Choose a finite set K of predecessor fields. For each transition fi→fi+1, append fi+1 to Q[fi] if fi∈K, otherwise append to the default queue. Transmit f0 and those ordered queues. Decoder's already-emitted last field determines which queue supplies its next field. No occurrence positions or routing bitmap is transmitted.

Initial construction used JSON arrays of fields and had132plans/0raw wins. Repaired serialization uses a queue string split on ASCII space, retaining empties, or JSON null for a truly empty queue. This removes per-field quotes without conflating zero fields with one empty field. Contract and decoder changed together; all gates reran. Final138plans/0raw wins on34sources. Array-stage receipt is preserved, not counted as final evidence.

**Induction:** after t emitted fields, the output equals the source prefix and each queue has consumed precisely the transitions whose predecessor occurrence is before t−1. The next selected queue is the one used by the encoder at transition ft−1→ft; FIFO order puts ft at its head. Induct to all transitions. With exact split/join and UTF-8-stable source, equality of restored fields yields original bytes. This is a transparent pen-and-paper proof of the construction, not a Lean proof of JavaScript.

**Novelty scope:** unlike THESI there are no transmitted occurrence ordinals; unlike SYMFRAZ routing depends on decoded history rather than a frozen skeleton's sorted contexts; unlike DEIKTIS it does not emit relative references; unlike EUTAXIA it needs no monotone source keys; unlike BWT it transmits no sorted cyclic-rotation column or primary index. It is a classical finite-context/ordered-graph representation adapted to a self-contained textual parent interface, not new information theory or a claim that humans missed context modeling. Repository searches for Euler/rotor/successor-queue/adjacency-list wires found no matching codec; this is bounded novelty inspection, not a theorem about every historical branch.

**Greediness/bounds:** deterministic frequency ranking of predecessor fields occurring≥3times, ties by first occurrence; top1,2,4,8,16,32sets. Six plans maximum; no iterative greedy wire search. Choosing top frequencies is a heuristic, not a token optimum. One best-raw plan gets a parent call. Expected map-based construction O(n+v log v) plus six tokenizations, O(n)storage; inverse O(wire+output) aside from implementation/library costs, with≤50,000units output and≤1024contexts. JS map worst-case and parent runtime are not newly formally bounded. The parent can be expensive or fail; no clock-based candidate pruning changes wires.
