## ANAGNORISIS — public-canon recognition codec (+ CRASIS, + vendored PR #27/#28 surfaces)

**What is new.** Every codec in the registry so far was *closed-world*: every byte the reader
emits is derived from bytes in the message, so a glyph costs its own definition. The reader is a
language model, and it already holds — verbatim — the standard open-source licence texts and
per-file notices (Carlini et al. 2021 showed GPT-2 memorises the entire MIT licence). ANAGNORISIS
recognises those texts in a message under any per-line comment prefix, re-wrap width, URL scheme,
indentation, tab rendering, dropped appendix or CRLF, replaces them by a short reference the
reader already understands, runs DAEDALUS on the rest, and inlines a one-line contract compiled
from the features actually used:

```
【L】 = the standard text of license L as in GitHub's LICENSE template, after the copyright line.
MIT License

Copyright (c) Meta Platforms, Inc. and affiliates.

【MIT】
```

41 tokens for `holdout/lic-mit.txt` (raw 223, DAEDALUS 223). `【Apache-2.0: 2026 OpenAI】` is a
46-token message for a 2258-token LICENSE file. `# 【Apache-2.0 header; prefix "# "】` saves
71 tokens on a 296-token TensorFlow source file.

**Receipts** (`bench/z45/REPORT.md`, `bench/z45/receipts/SUMMARY.md`; o200k_base, `OMEGA_DET=1`,
contract counted, every row byte-exact):

- Shipped lanes: byte-identical to DAEDALUS on 21 of 22 files (Δ = 0); lic-mit 223 → **41**.
- Fresh corpus fetched live from 90 repositories (`bench/z45/corpus`): recognised 63/87 LICENSE
  files and 20/43 headered sources; LICENSE files with a recognised text cost 30–116 tokens
  instead of 220–7446; headered sources save 70–180 tokens each.
- Independent CPython reader (`bench/anagnorisis_decode.py`, shares no code with the encoder):
  26/26 wires byte-identical.
- Reader-side claim tested, not assumed: from-memory reproductions written before reading the
  canonical files and diffed by tool (`bench/z45/canon/memory/`): MIT, BSD-2, BSD-3, Unlicense,
  WTFPL, 0BSD byte-exact; Apache/GPL-3 notices exact modulo indentation; ISC (wrap), Zlib (one
  space — which turned out to be the upstream text), MPL (http/https) not. The catalogue is split
  into a `memorized` tier and a `catalog` tier accordingly, and every reference reports its tier.
- Catalogue provenance: github/choosealicense.com `_licenses/*.txt` @ `f717b235` (the templates
  GitHub inserts into repositories), generated by `bench/z45/build-canon.py`; not this
  repository's fixtures.

**Honest limits.** A lane codec, not a prose codec; messages without canonical text get the plain
frontier message unchanged. Three MIT renderings and the `ending`/`tabs` modifiers were added
after looking at the corpus (in-sample: 63/87; before them: 36/87). `wrap N` references are exact
for the library and for any reader that can count columns; they are reported separately.

**CRASIS** (`src/lib/omega/crasis.ts`): punctuation-boundary fusion where the tokenizer has a
compound token, then DAEDALUS, one-line restore contract. Exact everywhere, wins one lane by 6
tokens, loses by 1–7 elsewhere (guarded). Kept as the receipt that the sub-token direction on
prose is exhausted: ≈0.6 % headroom on hybrid text, and fusion removes the dictionary's own
material (§D.2 of the report).
