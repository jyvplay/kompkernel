## One-paragraph summary

A hexdump prints every byte twice — once as hex, once as an ASCII panel
— plus an offset that is 16 × the line index. That frame is invisible to
the whole stack for a different reason than computed columns were: the
gutter is *fresh semi-random characters each line*, so grammars price
it; it is not a vertical law; it is not a dependency between data
fields. It is a **second encoding of the same values under a fixed
external convention** (`od -t x1z`, `xxd`, `hexdump -C`). Grep over all
281 modules before this turn: `xxd`/`hexdump`/`gutter` = 0 hits.
DIPTYCHON infers the rendering parameters from the text, extracts the
bytes, **verifies a byte-identical re-render of the entire input**, and
only then strips the frame and composes with the cheapest measured
parent under the usual strict frontier gate. On real GNU `od` output
over `/bin/ls`, the frame is ~44% of the AKOLOUTHIA-2-coded message.

## A. Formal model

Same admissible-object/access/cost model as X51 §A (single UTF-16
strings identified as UTF-8 bytes; stock LLM in one chat message; cost =
complete-message o200k_base tokens; success = byte-exact decode ∧ strict
`<` vs the measured frontier minimum, exact fallback otherwise).
DIPTYCHON's candidate additionally requires the input to be a canonical
dump that re-renders byte-identically from inferred parameters (caps:
2,000,000 code units, 300,000 lines, ≥4 data lines, uniform EOL ending
the text). Adjacent non-substitutes: `xxd -r` to binary (not a chat
artifact; binary output is inadmissible), base64 of the byte stream
(illegible wire; rejected by repo precedent), shipping the dump through
gzip-shaped text (measured dead since z20), and GRAMMA's layout dialects
(position-derived indentation — the gutter is value-derived, a different
redundancy source; KLADOS makes the analogous distinction for tree
glyphs within the regeneration family).

2. **Symmetric-matrix triangular elision.** No codec owns it (grep:
   only unrelated "matrix" mentions), but the corpus contains **zero**
   symmetric numeric matrices. Not built on synthetic-only evidence.
3. **Totals-row / column-aggregate elision.** Zero totals rows in the
   corpus' delimited files. Not built.
4. **Citation-number first-appearance entailment.** Zero prose files
   with ≥15 `[n]` citations. Not built.
5. **Unit-conversion parentheticals** ("5 km (3.1 mi)"). Zero hits.
6. **Markdown self-links / HTML self-anchors / legal number-words /
   weekday parentheticals.** Zero hits each.
7. **Markdown pretty-table padding regeneration.** Present (11 files;
   `prose-readme-2` has 1,972 table tokens) but GRAMMA-class
   (position-derived layout) and space-runs tokenize cheaply; queued
   behind the value-derived candidate, not built this turn.
8. **Tree-art regeneration** — already owned by KLADIOS (found by grep
   before building; this is the detector working).
9. **`ip a` broadcast-address entailment** and similar one-off ops
   identities: real but a handful of instances per output; below
   contract floor. Not built.

Look-alikes that are not the mechanism (detector = whole-input
byte-exact re-render): trusting the gutter instead of the hex (gutter is
lossy — 0x00 and 0x80 both render '.'), assuming 16 bytes/line for xxd
`-c` variants (parameterized instead), assuming squeeze semantics are
uniform (xxd autoskip squeezes only NUL lines; a trailing autoskip `*`
with no following offset does not determine the byte count and is
refused), treating the final offset line as data, and continuous-hex
reduced lines colliding with verbatim hex-looking lines (refused by the
restore-verify in the planner).

**`od-bin512.txt` (real, 512 B; DAEDALUS + AKOLOUTHIA-2 members) —
candidate 385 vs 414 (−29).** Both fast members tie (orig 414,
reduced 254; ~2–5 s each). At this size the ELF-header dump is mostly
grammar-friendly pattern, so the frame share through parents is small;
the 8 KiB lane shows the asymptotic share. Receipt
`bench-od-bin512-segmented.json`.

**Full TAGSTACK+SIBLING frontier on hexdump lanes: not measured.**
Four attempts (2 KiB DET 34 min, 1 KiB DET 22 min, 512 B DET 12 min,
512 B live-clock 12 min) were stopped without completion; DAEDALUS and
AKOLOUTHIA-2 individually finish in seconds, so the sink is APOGRAPHE
(>1,500 s alone on the 8 KiB lane) or another frontier parent on hex
text — profiling it is a recorded next task. Until the gate is
affordable on a lane, the shipped codec returns the measured best
parent there, exactly as SYLLOGISMOS does on airport. The strict
member-level wins above are therefore *necessary-condition* evidence,
not full-frontier claims; they are labelled as such everywhere.
