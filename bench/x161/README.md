# X161 — KAMPYLI (curvature): exact finite-difference table programs

## A–B. Model, admissible objects, information/access

Source x is a UTF8-stable string of at most50,000 UTF16 code units; bytes of the
original file are the ground truth. No normalization, approximate arithmetic,
training, skills.md, prior chat, system prompt or external dictionary is allowed.
KAMPYLI recognizes contiguous numeric tables:8–2000 rows/block,1–16 columns,
exactly one space/tab/comma between fields, canonical signed decimal integers
(no leading zeroes, no -0), magnitudes strictly below10^24. Every column has
constant finite differences by degree<=4 and at least one has degree2–4.
Other text, separators, final LF and non-ASCII prose are retained exactly.
Reserved `!curve` source collision rejects the plan. Mixed/ragged blocks may
split; an accepted subblock is still reconstructed byte-for-byte.

Actually available: shell, git/gh, Node/npm/esbuild/TypeScript/Vite, Python,
public web search/fetch. No independent agents, model API, simulator, Lean/lake
or expert reviewer. Concurrent shell workers are real processes, not agents.
Published notebooks are parsed as data; their code is not blindly executed.

## Construction and proof obligation

`!curve N S a,d,...;a,d,...` replaces a whole table block. S specifies its exact
field separator; each semicolon-separated vector initializes one column.
Emit each first value, then update differences left-to-right by adding the next
value. All update operations use the previous next entry because left-to-right
has not yet modified it. Do not reverse the update order.

For seed vector d_0,...,d_k, row r equals Σ_j binom(r,j)d_j. Pascal's identity
proves that advancing the difference vector emits row r+1. Encoder computes
actual source differences, requires the final level constant, and verifies every
reconstructed block and whole source. This is classical Newton forward-difference
coding. No new theorem or private AI-native insight is claimed.

Novelty audit: APOGRAPHE/METRON/AKOLOUTHIA generate constant or affine progressions;
ATHROISMOS integrates explicitly transmitted same-row drivers; SYZYGIA/ZYGON
fit cross-column affine relations; KLIMAX follows outline successors; HAPLOGRAPHE
regenerates Git path roles. KAMPYLI transmits a CLOSED higher-order difference
state, not row drivers or literal later values. SOLARIS's polynomial terminology
was inspected: its implementation mines repeated phrases, not numeric polynomial
sequences. This is the repository addition, not historical algorithmic novelty.
