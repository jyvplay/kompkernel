# X53 — TAXIS: derived columns where the delimiters are spaces

## Summary

X53 ships **TAXIS** (`src/lib/omega/taxis.ts`, key `taxis`, exact, deep):
derived-column elision for **space-aligned tables** (`ps aux`, `top`, `df`),
restored by **exact re-alignment under the original header**. The mechanism
has two parts, neither present in the 282-module stack: (1) *column-geometry
inference with byte-exact re-rendering* — header-word anchors, per-column
L/R alignment, per-transition minimum gaps, push-right-whole on overflow
(the rule set that survives procps' overflow rows, found this turn), and
(2) *ops-shaped derived-column families* SYLLOGISMOS cannot express —
fitted-total percent (ps %MEM is `100·RSS/T` truncated to tenths with `T`
solved from the rows as an exact rational interval; `top`'s is the rounded
form), percent-of-column, ceil-share `A/(A+B)` (df Use%), exact binary
arithmetic at the target's scale. X51 had already verified the ps identity
(59/59) and named whitespace alignment SYLLOGISMOS' documented boundary;
X53 crosses it.

Verification so far: red team 241 checks (1 miss, analysed and fixed — see
§G; re-run [PENDING]), independent Python decoder byte-exact on 6/6 lanes
from the contract text alone, blind contract-only decodes **byte-exact on
all 3 fresh samples** (24-row ps, 14-row ceil-share, 50-row endurance —
the X52 reader-endurance task, §H). Frontier repeat: **210 exactly**,
fourth consecutive turn. Bench: [PENDING segmented receipts].

## A. Formal Model

A codec C is a triple (contract K, encoder E, reader R). For input text T,
one chat message M = K + E(T) must let a stock LLM (no system prompt, no
skills.md, no tools) output exactly T, byte for byte. Cost is the o200k_base
token count of the complete message. TAXIS is admissible when its plan
exists: a contiguous block of `lines[h..h+R]` (header + R ≥ 4 data rows)
such that:

- **Cells.** Every block line tokenizes into n ≥ 3 fields (first n−1 are
  maximal non-space runs; the last is the remainder of the line), no line
  has trailing spaces, and the header row tokenizes the same way (its last
  cell may contain spaces: `Mounted on`).
- **Geometry.** With header word spans `[hs_j, he_j)`, aligns `a_j ∈ {L,R}`
  (a_{n−1}=L) and gaps `g_j ≥ 1`, rendering places fields left-to-right:
  L: `start = max(hs_j, prevEnd + g_{j−1})`; R: `end = max(he_j,
  prevEnd + g_{j−1} + len)`, (column 0 R: `end = max(he_0, len)`); the fit
  is accepted iff re-rendering all rows from bare cells reproduces the
  block byte-for-byte.
- **Relations.** A derived column is a family instance (fittedPct /
  pctOf / ceilShare / arith) whose computed rendering equals the cell
  text on **every** row, checked in BigInt rational arithmetic.
- **Emission.** Reduced = original lines with block rows single-space
  joined minus derived columns; candidate = contract + cheapest measured
  parent message on reduced; emitted only if candidate is byte-exact and
  strictly below the same-source TAGSTACK+SIBLING frontier; else the
  measured best parent is returned (no-regression fallback).

## B. Outcome Space

- **H+ (solved):** a brand-new mechanism, byte-perfect, one-chat readable,
  strictly below the measured same-source frontier by more than a few
  tokens on at least one honest everyday lane, with independent
  verification (red team + second implementation + blind decode).
- **H− (not solved):** no admissible new mechanism found, or candidates
  collapse to existing codecs / fail the gate everywhere.
- **H∂ (partial):** mechanism shipped and verified, wins at
  frontier-*member* level or on narrow lanes only; claims scoped to
  receipts.

## D. Negative Space (look-alikes and the modal shortcut)

The modal shortcut in this problem family is "another dictionary/template
trick on repeated text". A **detector**: after the transform, the removed
positions must not be copies of anything sent — check that the elided
values occur with fresh digits (e.g., %MEM `6.6` is not a substring of the
RSS `269296` that determines it via division). Look-alikes checked against
the whole stack before claiming novelty (greps over 282 modules + header
reads): ENTHYMEME/EPAGOGE (public-convention entailment — owns slugs and
JVM frames; different table model: none, they splice within lines),
SYLLOGISMOS (delimited FDs, binary arithmetic — cannot parse aligned
text, cannot express A/(A+B) or a fitted global total), APOGRAPHE/KOLUMN
(column laws in delimited/aligned tables — no cross-column arithmetic,
no geometry restoration), AKOLOUTHIA-2/DAEDALUS (repetition), GRAMMA/
KLADIOS (position-derived layout), DIPTYCHON (value-derived dual
renderings of byte dumps), TAGSTACK (stack-derived tag names),
ANAGNORISIS/WORD-CANON (imported text). TAXIS = entailment genus,
but the *table model* (inferred anchors/aligns/gaps + exact re-alignment,
a column-global layout function) and the *relation families* (fitted
constant, share-of-sum) are new to the stack; SYLLOGISMOS' own header and
X51 report name whitespace tables as its boundary.

## E. Approaches (≥6, mechanism-distinct)

1. **Anchor-slug entailment** (prose) — construction: elide `(#slug)` when
   `slugify(text)==slug`. Artifact: `probe1.py`, `probe2.ts`. Proved:
   mass exists (383/535). Interface: **owned by ENTHYMEME/EPAGOGE** —
   cheapest falsification was the inventory grep; it fired. Local-vs-
   original gap: none (it *is* the existing mechanism).
2. **Span-art re-rendering (gcc diagnostics, "OBELOS")** — construction:
   parse header/excerpt/marker blocks, ship span geometry, re-render
   caret lines. Artifact: `probe3.ts` (byte-exact on 125 real
   diagnostics). Proved: geometry derivation sound. Cheapest
   falsification: parent measurement — fired (692 vs 707 on repetitive;
   diverse corpus surplus 118 before contract ≈ wash). Gap: token
   economics, not correctness.
3. **Diff hunk arithmetic** — construction: elide `,b`/`,d` (body
   counts). Proved: 0.09% mass on 1.55 MB real diff. Killed by census.
4. **Hierarchical aggregates** (JSON count=len, du sums) — proved: du
   5/6 exact (own-blocks), JSON mass ~digits. Killed by exactness/mass.
5. **Aligned-table derived columns (TAXIS — shipped)** — construction
   §A. Artifact: `src/lib/omega/taxis.ts`. Proved portions: geometry fit
   on all ps/top lanes + ls-l-dts; families verified per-row in BigInt;
   whole-input restore acceptance. Unresolved interface: none for
   correctness (wrong guesses refuse). Cheapest falsification: one
   violating row must kill the drop (red-teamed, §G). Local gap:
   contract is 82–90 tokens, so small/thin tables refuse by economics
   (z11 ps: only two distinct %MEM values — correct refusal).
6. **Reader-endurance variant for DIPTYCHON** (X52 task 1, gutter
   chunking) — not built; instead X53 quantified endurance where it is
   now load-bearing (TAXIS 50-row blind decode, §H) and DIPTYCHON's
   deficit stands as measured in X52. Recorded as future work, not
   claimed.

## G. Red team (second-order adversary; repairs inherit no trust)

`bench/x53/taxis-redteam.ts`, seed 0x5353, independent renderer written
from the contract rule: 90 synthetic tables (planted fittedPct trunc/
round, ceilShare, arith +/×, none), adversarial set (one violating row,
overflow cells, passthrough lines, CRLF, no-final-EOL, 3 rows, trailing
spaces, tab injection), live outputs of `ps/df -k/df -h/top/vmstat/free/
ls -l` from this sandbox's binaries, negative prose/CSV, 2 full encodes.
First run: **241 checks, 1 failure** — a synthetic ceilShare table whose
first column was right-aligned with values wider than the header word.
Root cause: `fitGap(0,'R')` required every first-column end to equal the
header end; wide first-column values legitimately end later
(`end = max(he, len)`). **Repair:** column-0 R allows overflow ends;
renderBlock hardened against negative padding. The repair was treated as
a new object: full red team re-run [PENDING], plus the Python decoder
implements the same column-0 rule and still decodes all lanes. Spurious
rules on random no-rule tables: 0/15. Planted-rule recall: fittedPct
22/22, arith 34/34, ceilShare 18/19→(fixed case) [PENDING re-run].

Second-order attacks considered in design: (a) degenerate fittedPct on
all-zero columns — blocked by distinct-≥3 + ≥2 positive rows + integer-T
interval; (b) interval-boundary T — shipped T is render-verified on
every row (both endpoints tried); (c) header-name collisions — contract
falls back to `column k (name)`; (d) parent marker collisions in reduced
text (`§`/`¶` make DAEDALUS arms refuse — found during OBELOS probe;
TAXIS reduced text is plain table text, and the contract is never
parent-encoded); (e) a table block starting at a bogus "header" — fit +
restore acceptance makes false positives harmless (they must still
round-trip and beat the frontier).
