# X162 — AKROSTICHIS: exact glossary-label projection

## A–B. Model and access

The source is a UTF8-stable string, at most 50,000 UTF16 code units. Ground truth is the original file's bytes, not the encoder's decoded field. No normalization, external acronym dictionary, skills file, training, prior chat or privileged system instruction is permitted. The wire includes all instructions and its compressed parent. Actual tools: Node/npm, TypeScript/esbuild/Vite, Python, git/gh and public web search/fetch. No Lean/lake, independent model endpoint, independent agents or expert review was available. Two shell workers are processes, not agents.

T(m) is reference o200k_base count of the complete message. Exactness requires D(E(x))=x in original bytes for every admitted x. H+ (requested strong result): exactness, complete-price improvement, strong baseline, independent one-basic-chat decoding, runtime non-regression, and broad prose/ops/everyday coverage. H−: an actual component counterexample, not merely an unfinished experiment. H∂: a restricted exact token improvement with missing native or performance evidence. X162 is H∂. Equality tolerances are zero bytes/tokens. Speed gate: ≥10% lower aggregate CPU AND process wall, no lane regression, all wires identical, cold ABBA on three protected lanes. Merge/release authorization is distinct from scientific acceptance. Universal strict shortening of all finite strings over the same finite alphabet is impossible by injective counting; this is not a refutation of selected-family compression. ## Construction and proof argument

A standalone 2–16-character uppercase ASCII/digit label is eligible only when equal to the exact uppercase ASCII letters/digits of the next four-space-indented definition, stopping before its first ` [` citation boundary. Replace that label line with standalone `^`; preserve the entire definition and every other character. Refuse any source already containing a standalone `^`. Inversion restores exactly the tested projection. Eligible labels cannot be definitions (they do not begin with four spaces), so sites do not overlap and inversion changes no determining definition. Equality at admission plus disjointness establishes the string inverse; UTF8 stability lifts it to bytes. Cap and collision checks fail closed.

The selector compares complete incumbent, direct instructed folding and instructed compressed parent; it accepts only a strictly smaller independently readback-equal candidate. One parent call maximum after eligibility, zero otherwise. Projection/inversion are O(n) time/space for bounded n; selector cost is O(n) plus complete tokenization and one inherited parent search, whose substantial cost is NOT linear or free. Deterministic all-site folding is not greedy substring search and makes no global optimality claim. Native ambiguity about parent-first ordering still needs behavioral testing.
