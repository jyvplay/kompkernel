# X144b formal review and evidence thresholds

This continuation preserves X144's negative PSIFIDA experiment. Its A–J contract and adjacent-problem exclusions remain in `../x144/REVIEW.md`; this document states the changed objects, proofs, tests and decisions. No proof assistant or blind model evaluator ran.

## Model, quantifiers, outcomes
Admissible source: a UTF-8 byte string whose decoding/re-encoding is identical. The production public TAGSTACK path now rejects lone UTF-16 surrogates instead of pretending that replacement-character transport is lossless. COLEX transforms at most 50,000 UTF-16 units; larger valid inputs fall back to raw identity. No external dictionary, source oracle or previous-message state is available to the reader. All instructions and parent framing count toward o200k_base message cost. Full message UTF-8 stability is a separate mandatory invariant, not implied by an in-memory inverse.

Choose implementation/protocol before evaluating sources. For every frozen evaluation source require emitted-message transport stability and source-byte reconstruction; require complete-message tokens no higher than the valid baseline on all lanes and >=11 tokens saved on at least one. Broad prose/ops superiority additionally needs gains in both categories. Require independent native one-chat output exactness before calling a codec natively verified. A speed claim needs isolated full-encoder timings, not a helper microbench. H+ requires all mandatory gates. H− is candidate-local when measured price loses, not an impossibility proof for the whole research problem. H-boundary includes a correctness repair with higher token cost, token wins lacking native evidence, partial reader coverage, and finite workload speed measurements. Universal strict shortening remains impossible by the finite-alphabet counting argument; that does not decide this finite corpus.

## COLEX construction and invariant
Inside each maximal `[A-Za-z0-9_./+-]+` run split on one declared separator (`/`, `-`, `_`, `.`), reverse the component sequence, and join on the same separator, including empty components. The maximal run alphabet is invariant under this operation; outside separators/Unicode/whitespace remain untouched. Split and join are inverses on this list representation, and list reversal is an involution, so applying the same transform twice returns exactly the source. No Unicode grapheme is split because only ASCII lexemes are changed. Leading/trailing and repeated separators are handled by empty components, not silently discarded.

Exhaustive standalone search over four separator choices, no greedy local edits. Every complete key+payload is priced. Parent allocation is heuristic: one cheapest standalone arm on each of two predeclared prose lanes (KB/email) and two ops lanes (du/apt); fresh heldout sources each get one best standalone arm. This is not an exhaustive parent optimum. O(4L) transform work plus tokenization; TAGSTACK parent encodes dominate. No wrapper-wide wall-time bound is claimed.

Repository-scoped distinction: ANAKYKLI rotates document segments, EUTAXIA permutes fields, METABOLE edits words from history, PSIFIDA transposes digits. COLEX reverses lexical *components*, not characters or records. Classical suffix/colex locality ancestry is acknowledged. The source inventory and targeted searches are not a proof against every possible semantic equivalent or training-data antecedent.

## Transport admission repair
Induction on selector updates: the base comparator admits only stable complete messages, with raw identity available if no valid parent remains. The table candidate, ordinary admission, parent-relative admission, and all three direct rewrite sites test stability before replacing the incumbent. Thus every admitted best message is stable, assuming source validity. Existing exactness gates remain in place. Stability alone is NOT a proof that a decoder is correct.

The experimental predicate fast path uses a native regex to accept strings containing no surrogate code units. Otherwise a high half must be immediately followed by a low half, and an unmatched low half rejects. All 65,536 single code units plus composed adversaries are checked against actual UTF-8 round trips. A repaired candidate inherits no trust: Vite/Drizzle/git-log are freshly encoded; Vite is tested with and without memoization; all exported encoder routes are attacked with invalid sources; six further end-to-end fixtures cover CRLF, variation selectors, ZWJ sequences, NUL, and Unicode boundary scalars. The initial reused COLEX harness omitted the separator argument and threw; the harness was repaired, rerun, and a missing-separator rejection test added.

## Six distinct tracks, artifacts and attackers
1. **COLEX / lexical permutation:** `colex.ts`, probe/parent/heldout receipts. Proof: involution above; unresolved cost/native execution. Attack repeated/empty components and mixed punctuation. Cheapest falsifier complete-message price. Native gap remains original.
2. **Positional copying:** rerun `controls.ts` JSON backreferences. Executable inverse; references cost tokens and require exact indexing. Attack future/overlap and codepoint/code-unit confusion. Price/replay falsifies the local format, not all copying schemes.
3. **Entropy coding:** Brotli/base64 arm in `controls.ts`. Program byte inverse checked. Missing native decoder is the structural attacker; this remains outside the access contract despite possible byte compression.
4. **Numeric prediction:** rerun `delta_control.ts`. Existing DIAPHORA residual inverse checked. Attack carries, width changes and irregular identifiers. Gap is local model applicability and then original native gate.
5. **Transformed phrase images:** rerun `image_census.ts`. Searches long phrase pairs and existing EIKON images. Attack lack of reusable transformed pairs and noninjective case maps. Census is concrete evidence, not a theorem about all corpora.
6. **Layout prediction:** rerun `layout.ts` PTYCHE control. Existing greedy wrapping with explicit residuals. Attack long words, CR/LF, spacing and line-count errors. Frozen PTYCHE/KREMA packet hashes rechecked, but real blind evaluation still NOT_RUN.

## External verification and stopping
Actual systems: shell, Node, TypeScript/esbuild/Vite, Python, Git/GitHub and web tools. No independent agents, simulators, theorem provers, external database or blind LLM endpoint established. Independent Python readers give implementation diversity, not independent behavioral verification. Imported results are scoped in research.md; none supplies native decoding or a terminal codec. Merge permission comes from the latest end-of-turn merge request, not from passing the codec-superiority gate. Losing experimental codecs remain unwired. Do not report the repair's higher-cost valid Vite output as a token win.

Final timing result rejected the regex fast path; production uses the simple scan. The two predicates passed 171,072 differential comparisons. All affected correctness and compiler/build gates were rerun after removing the fast path.
