## Compression ancestry and access-model checks

* Bhadade and Trivedi, *Lossless Text Compression using Dictionaries* (2011), https://www.ijcaonline.org/volume13/number8/pxc3871767.pdf — fetched chunks 0 and 2. Section 4.1 uses word, prefix, suffix and nonword dictionaries, including a two-pass frequency order and row/column indices. This defeats any claim that dynamic word/prefix precompression itself is new. MNEMA instead emits a prefix of the latest matching already reconstructed word; that is a repository experiment, not a new mathematical family. Bit savings followed by arithmetic/BZIP2 coding are not native-chat token savings.
* Zavadskyi, Klein, Shapira, *Context-Aware Word-Based Forward Coding*, Informatica 37(1),229–249 (March 6,2026), DOI 10.15388/26-INFOR621, https://informatica.vu.lt/journal/INFORMATICA/article/1403/text — fetched chunks 0–1 only. Forward frequencies decrement as symbols are consumed; the paper explicitly distinguishes net code from frequency/dictionary headers, and retrieval settings with dictionaries already available from archival settings. Its stated net Huffman improvement does not establish a shorter all-in chat message. Its order-one forward PPM escape calculation requires paid future statistics. Remaining proof sections not replayed.
* Kuratov et al., *Cramming 1568 Tokens into a Single Vector and Back Again*, ACL 2025, DOI 10.18653/v1/2025.acl-long.948, https://aclanthology.org/2025.acl-long.948/ — abstract inspected. Learned real-vector interface and sample optimization are different resources from a single ordinary textual chat. Not a byte-perfect native-text codec theorem.
