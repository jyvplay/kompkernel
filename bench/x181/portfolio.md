## X181-specific bounds and compatibility

Foata's theorem applies to words with repeated symbols over a total order; it
is not the first fundamental transformation on distinct permutations. Its
maj/inv invariant is explicitly tested but never substituted for token savings.
New fixtures (Python errors tutorial and Git object-recovery how-to) were fetched
after the mechanism was fixed. These are held-out source tests, not blinded native
LLM trials. No portfolio branch inherits another branch's inverse or performance.

AKRIBOS is a verification branch: a bounded strict parent reader with executable
malformed-envelope, Unicode, expansion and missing-dictionary tests. Its local
gap is four refused parent grammars, not the entire compression problem. The
speed branch is a 2 MiB direct-mapped exact pair cache; its attacker deliberately
creates colliding keys and checks eviction, including signed 32-bit extremes.
Count/vector/pair and whole-stack ABBA gates, not the cache microtest, decide
whether it improves system speed. These support branches are not counted as
new compression mechanisms.
