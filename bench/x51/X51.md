# X51 — ΑΝΑΓΕΝΝΗΣΙΣ (ANAGENNĒSIS)

**A value the reader can regenerate is not sent.**

`src/lib/omega/anagennesis.ts` · registry key `anagennesis` · family `exact` ·
fidelity `exact` · X51.

## 1. The seam

Every codec in this repository that makes a value cheaper makes it cheaper by
**sending it differently** — a glyph instead of the literal (DAEDALUS, CHIRON),
a mask instead of the separator (TYPOS, APOGRAPHE), a ramp instead of the column
(METRON), a brace expansion instead of the lines (DENS-2). All of them still
send the value.

GNOMON R2 is the one exception: it writes `"resolved": "~"` and the reader
rebuilds `https://registry.npmjs.org/NAME/-/BASE-VERSION.tgz` from the entry key
and the entry version. Measured on `package-lock-head.json`: **one rule, −336
tokens (5463 → 5127)**, the largest single-rule win in the stack.

GNOMON's rule is hand-authored and reads one file. ΑΝΑΓΕΝΝΗΣΙΣ asks the question
it implies: **which other values in a document are regenerable?**

> A value is regenerable when it is a function of other values the reader was
> already sent **in the same record**.

That is STIGME's economics — buy redundancy at the **contract** rate, not the
**payload** rate — moved from *punctuation* to *values*. It is AI-native for the
same reason STIGME is: a byte-level decoder cannot regenerate a value it was
never sent; a reasoning reader can.

## 2. Mechanism

1. **Records.** A line ending in `{` opens a record and names it; a line starting
   with `}` closes it. A record's string members are the `"name": "value",` lines
   inside it. A record's sources are **its own key** and **its own members**.
   The document's own top-level object is the synthetic root and is a record too.
2. **Family.** Records sharing a member name form a family. Fewer than three
   members → ignored (a sentence has to amortise).
3. **Template mining.** Longest common prefix of the family's values is a literal.
   The residue is parsed left to right; at each step the parser takes the first
   move that matches **every** member:
   (a) a reference that swallows ≥ 8 characters,
   (b) the longest common literal prefix (≥ 2 chars),
   (c) a shorter reference,
   (d) a one-character literal.
   References are `FIELD(x)`, `KEY`, `STRIP(X,p)`, `TAIL(X)`, `HEAD(X)`.
   `STRIP`'s prefix is the longest prefix of the source that is **not** a prefix
   of the residue, and is kept only if it is the same string in every member.
   The parse backtracks (a literal is given back character by character) and is
   budget-bounded; a family needing more is **dropped**, not approximated.
4. **The wire.** Every matched value becomes `~`. The reduced text goes through
   DAEDALUS **or** GRAMMA; the contract gets one sentence per rule. The reader
   expands glyphs first, regenerates values last.
5. **Guard.** (a) the rule set round-trips the input byte-exactly on its own;
   (b) the composed wire decodes back to the original through the real decoder.
   The tournament contains the plain arms, so the emitted message is **never
   above the frontier**.

## 3. The mined rule, and what it costs

For `bench/holdout-ops/package-lock-head.json` the miner returns:

```
field    resolved        hits 62       saved 4826 chars
shape    L28 | strip(KEY) | L3 | tail(KEY) | L1 | field(version) | L4
sentence ~ in the "resolved" field = "https://registry.npmjs.org/@"
            + the key minus "node_modules/@" + "/-/" + last segment of the key
            + "-" + version + ".tgz".
```

That is GNOMON's `NAME` / `BASE` / `VERSION` derivation written as
`STRIP(KEY, "node_modules/@")` / `TAIL(KEY)` / `FIELD(version)` — **discovered,
not written**.

## 7. Honest scope

This is a **single-lane win**, on the largest lane in the corpus, from a
mechanism no other codec in the stack has: a value that is a function of its own
record is not transmitted. It is **not** a general prose win and **not** a
general ops win, and it is not claimed as one. The 17-lane suite is unchanged;
the frontier is exactly as last turn.

## 8. Correctness

Every arm is guarded twice, and the tournament always contains the plain arms.
All 17 suite lanes plus `package-lock-head.json`, `gh-api.json.txt`,
`json-pkg.txt` and `metrics.tsv` were checked `decoded === text`; all exact.

## 9. Prior art

GNOMON (X54) is the direct neighbour and the reason this codec exists. STIGME
(X19) is the same economics on punctuation. ONTO (arXiv 2604.17512) deletes
JSON keys schema-once — a *schema* elision, not a *value* regeneration, and it
does not mine the template. The dictionary-encoding line (arXiv 2604.13066,
2506.00307) transmits a dictionary; here nothing is transmitted at all.

## 10. Time / CPU

`anagennesisEncode` runs DAEDALUS and GRAMMA once each on the raw text, then for
each non-empty rule subset (at most 15) runs DAEDALUS and GRAMMA again on the
reduced text. Measured per lane under `OMEGA_DET=1`: 1.7 s (json-pkg) to 79 s
(package-lock-head.json). The mining itself is a single pass over the lines plus
a bounded backtracking parse; it is milliseconds.
