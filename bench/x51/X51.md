## One-paragraph summary

In real tables, some columns carry **no information beyond the others** —
not because they repeat text, but because they are *computed from the
row*: an employment dataset column that is exactly `COUTAX × UNEMPF` on
all 32 rows; an `iso_country` that is `iso_region` before its dash on all
300 rows; a subject ID assembled as `"age" + age + "_" + gender`. The
whole existing stack is blind to this: grammar codecs see fresh digit
strings each row and must price them; the vertical-law codecs (AKOLOUTHIA-2,
METRON, KOLUMN, APOGRAPHE) model one column from its own values, its header,
or an identical sibling — none recomputes a field from **other fields in
the same row**, and none does decimal arithmetic at all (grep-verified over
all 280 `src/lib/omega/*.ts` files this turn). SYLLOGISMOS searches a bounded
family of functional dependencies, verifies each on **every row** with
BigInt-rational arithmetic and byte-identical CSV re-rendering, deletes
the dependent columns, states each dependency once in English, and composes
with the cheapest measured parent under a strict TAGSTACK+SIBLING frontier
gate. Measured outcomes are in "Gate results" below; the mechanism class
is established prior art (SPARTAN/SQUISH/DeepSqueeze/Blitzcrank) — the
novelty is only its exact, one-chat, LLM-readable realization in this repo.

## A. Formal model

- **Admissible objects.** Single TS `string`s (UTF-16 code units);
  "byte-perfect" = identity as UTF-8 bytes. The candidate transform
  further requires a delimited table with a total header parse
  (`,`/`\t`/`;`/`|`, ≤100,000 code units, ≤10,000 rows, ≤32 columns).
- **Access model.** Encoder: arbitrary CPU-bounded transformation.
  Decoder: a stock aqua-class LLM in one ordinary chat message, no
  system prompt, skills file, tool, or side channel. Human-legible
  grammar-text remains the reproducibility proxy for machine decode; the
  only model asked to decode a sample this turn is this one, disclosed
  below.
- **Counted resource.** Complete-message `o200k_base` tokens (contract +
  wire), through this repo's tokenizer. Never raw-wire or transform-only
  costs.
- **Success predicate.** `∃T. ∀x in L. decode(T(x)) ≡ x ∧ M(T(x)) < min
  measured frontier on x`, implemented per input as: byte-exact decode
  **and** strict `<` versus the measured frontier minimum, with exact
  fallback otherwise. Failure = returning the measured best parent.
- **Adjacent non-substitutes.** gzip/zstd/base64/binary (illegible);
  gzip-shaped *text* (measured dead in z20 and repeatedly since);
  arithmetic coding of FD residuals (Blitzcrank-style: right idea,
  wrong substrate — not a chat artifact); learned entropy models over FDs
  (DeepSqueeze: heavy model + bit coder, inadmissible); lossy FD models
  (SPARTAN's approximate CaRT predictions: violate the predicate);
  propositional/two-way counting (25 turns of measured losses); public
  gzip-target books (not the target distribution).

## D. Negative space — look-alikes that are not the new mechanism

Detector for the modal shortcut ("find any redundancy and delete it"):
**a dependency is admissible only if it verifies on every row under the
exact CSV rendering, including scale and quoting.** Look-alikes rejected
by that detector, several measured dead this turn:

1. Constant-column drop — duplicate ownership (APOGRAPHE/KOLUMN); also
   constant *computed* targets rejected (spurious).
2. Duplicate column reference (`colM`) — identity, not a computation.
3. Vertical geometric/delta laws (`above`, `+b`, METRON magnitudes);
   `shiftdiff` here is removed from the wire, not re-encoded.
4. Grammar rule for the product column's digits (no recurrence exists).
5. Column dictionary / factor bit-packing (needs a bit coder).
6. Typographic zero-pad widening of IPs/versions — measured −raw but
   +22…+67 after parents (probe2, 9/9 lanes).
7. SemVer/IPv4 mixed-radix decimal packing — same, measured dead.
8. Disemvowel / function-word deletion — raw +150…+2,948, dead (probe1).
9. Aggregate elision without identity checks — `free -m` `used` is not
   reconstructible from the visible columns (`available` is a kernel
   estimate); `vmstat` CPU shares can total 101 (independent rounding);
   *would* be fantasy if shipped.
10. `git log --stat` totals as sums of visible counts — true in only
    3/10 fixture blocks (binaries/renames display no counts).
11. `du` parent sizes as child sums — true 2/62 in the fixture (sorted,
    truncated child sets; parents include the directory itself).
12. TOON-style JSON→table reshaping — repo z59: 62.4% of inputs could
    not even be produced by its spec; X51 searches confirm prompt-tax
    critiques (arXiv:2603.03306; arXiv:2605.29676 "Notation Matters":
    TOON −18% tokens at ~9pp accuracy cost with parse-failure cascades).
13. Nearest-neighbour/ICE learned HTML/table decompression
    (arXiv:2510.19000) — changes bytes; edge of predicate.
14. "Tokenizer compression" / number-base codecs measured regressing
    other terms (z27 tri-part proof) — never evaluate one repricing.
15. AICM four-mode ~5.6× lossy prose claim (offline dictionary, 15+KB
    side model) — breaks admissibility.
16. A "learned" dependency surviving by accident on few rows — the
    exactness predicate is indifferent to spuriousness **for this input**,
    but the value would be fake generality; documented where encountered
    (e.g. `csv-5.csv` `plate` "substring" hit is a constant column).

## E. Mechanism portfolio (≥6, each with falsification)

1. **Functional-dependency elision (CHOSEN: SYLLOGISMOS).** Artifact: the
   codec. Proved portion: any emitted relation reproduces every removed
   field under the exact original rendering (verified in-encoder,
   red-team, independent Python decoder). Cheapest falsifier: one byte
   mismatch anywhere kills the lane and is returned as failure. Unresolved
   interface: LLM per-row arithmetic at 300-row scale (blind-tested at 16
   rows). Local-vs-original gap: solves the local subproblem *exactly* for
   the detected relation; joint drop-set selection is greedy — no
   optimality claim (consistent with the new greedy-superstring hardness).
2. **SemVer/IPv4 mixed-radix packing.** Probe2 measured: loses everywhere
   through DAEDALUS (e.g. real `apt` lane 960 → 1,001 complete). Falsified.
3. **Disemvowel/function-word drop.** Probe1: inflates raw tokens before
   any parent. Falsified without parents.
4. **Hex-dump dual-representation elimination (`od` ASCII column).**
   Transform verified byte-exact in isolation on two real `od -A x -t x1z`
   fixtures (`bench/x51/receipts/od-roundtrip.out`): raw 21,517 → 16,993
   and 24,814 → 18,594. Parent measurement did **not** complete (DAEDALUS
   on 8 KB of hex under DET exceeded 6 CPU-minutes without finishing a
   single encode; the lane was deprioritized behind the SYLLOGISMOS
   gates). Status: exact transform in hand, complete-message value
   unproven — future work, not claimed.
5. **Aggregate-line entailment (git/du/free/diff counts).** Measured
   identities mostly false in situ (probe2). Only `diff` hunk counts
   hold — a 12-token ceiling, below contract value. Falsified by exactness
   probe; shipping them would fabricate values never entailed. One
   confirmed instance: `ps aux` %MEM is exact-fitted-truncation of
   RSS×100/K over 59/59 rows for K ∈ [4,028,000, 4,037,583] — kept as a
   documented boundary (whitespace alignment + 7-digit division burden),
   not shipped.
6. **Exact FD scan at corpus scale (existence test).** Probe3 over 126
   files: 93 non-duplicate FD hits + 16 duplicates; established benchmark
   relevance before construction. Correctly distinguished genuine
   instances (csv-3 product, airport ISO prefix, csv-5 concatenated ID)
   from duplicate/constant decoys (fx-4dp, VIX, `plate`).
7. **Corpus-wide re-probes of prior negative space** (sexagesimal
   quotients/remainders, row block inversions, mode-skeleton exception
   lists, numbering rung deletion, money micro-integer ratios) — re-run
   under complete-message counting in probe1 and remain dead, now with
   receipts rather than memory.

## F/G. Second-order attacks against the candidate

A(C) — an adversary that knows SYLLOGISMOS exists attacks: *look-alike
relations* (a product column with one row altered — the detector finds no
exact FD, nothing is dropped; red-team case 9), *inverse relations*
(`base = scaled × 8` is equally valid and may be preferred by mass — the
contract then asks for multiplication instead of division, which is
*easier* for the reader; red-team scaleK cases), *cyclic temptation*
(`ID` from `age`+`gender` while `gender` comes from `ID` — refused by the
acyclicity rule; this exact trap invalidated probe4's csv-5 number, see
below), *rendering traps* (gratuitously quoted headers/fields, mixed
decimal scales like `14952` vs `17039.5` in one product column — handled
by verbatim header bytes + exact-minimal rendering, or refused), *reader
burden* (a fitted 7-digit divisor is excluded by the short-K rule), and
*contract bloat* (a 592-token lookup contract on csv-5 makes the gate
reject — the failure mode is fallback, never a wrong byte). The second-
order effect on the *frontier itself*: SYLLOGISMOS composes *under* the
existing parents, so it can only tighten the frontier on computed-column
tables; it cannot regress any lane (fallback is the measured best parent).
