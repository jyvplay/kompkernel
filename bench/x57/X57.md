## 2. The stack speed repair: deterministic counted-work budgets

**Problem (measured).** Full-gate and frontier encodes took minutes to
(measured X54) >900 s per parent on pathological inputs. This turn priced
the sink precisely on od8 (600 chars of hex dump): pre-repair
`archetyponEncode` = 79.3–83.5 s, exact, 142 tokens, with **3,132
`renderBest` calls and 7.06M `scoreRunCostDelta` calls** and 28.2M
short-tokenizer calls (one-shot instrumentation, later removed; receipts in
`budget-sweep.md`). Tokenizer memo hit-rates are 94.7%/97.6% — the caches
work; the pathology is **call volume from wrapper-chain re-entry**
(`renderBest` subtree callers: `evaluate` 61.9%, `buildOn` 13.7%).
Per-`renderBest` work is similar on healthy and pathological lanes
(maxima 10.7k/17.3k/11.5k score deltas), so per-call caps cannot fix it.

**Repair (deterministic, not clock-based).** `src/lib/omega/workmeter.ts`:
a module-level counted-work budget. `scoreRunCostDelta` (ARIADNE) ticks it;
the hill-climb stops accepting probes once spent, and `renderBest` gains an
exhausted-entry shortcut that materialises the baseline pool-order
assignment (still an exact candidate) without building pattern tables.
Budget windows are **per frontier parent** (TAGSTACK `consider` parents) and
**per ARCHETYPON identity arm** — a shared window was measured to starve
later parents (metrics.tsv degraded 210→236 before this was fixed; the
starvation data is in `budget-sweep.md`, kept as a disclosure). Default
`workBudgetFor(chars) = 2,000,000 + 100·chars` per window, 10–20× above the
measured knees (metrics TAGSTACK stays 210 down to 100k/parent; od8 keeps
142 from 200k). `OMEGA_WORK_BUDGET` overrides (≤0 = unbounded = pre-X57
behavior). Because the budget counts evaluations, output is a function of
the input only — no load-dependent wires (the old G10 failure mode).

**Measured effect** (`budget-sweep.md`, parity logs):

| lane | pre-repair | post-repair (default) | output |
| --- | --- | --- | --- |
| tagstack metrics.tsv | 304.0 s | 110.0 s | byte-identical (sha f0e0ffb9…) |
| archetypon od8 (600 ch hex) | 83.5 s | 14.8 s @200k knee; faster floor with shortcut | 142 tok identical ≥200k |
| archetypon lic-mit | 4.32 s | 4.38 s | byte-identical |
| synkrisis license.txt | 31.9 s | 31.9 s | byte-identical |
| frontier repeat (full) | 274.5 s (X56) | 115.2 s | 210, gate-identical |
| synkrisis od-bin512 (2,407 ch) | >900 s (X54, killed) | 192.3 s (receipt `pathology-odbin512.log`) | exact, 365 tok; unbounded output never obtained, so byte-parity on this extreme lane is *unverified* — the budget binds here by design |

Honest bound: a budget that binds *hard* can change outputs (od8 @100k =
147 vs 142; shared-window starvation = 236). Shipped constants keep every
lane measured here byte-identical; `OMEGA_WORK_BUDGET=0` restores unbounded
search everywhere.

## 3. SYZYGIA — the new codec

**Gap.** The affine map `y = a·x + b` between two *columns* (a≠1, b≠0) is
expressible by no union member (read from source this turn): SYLLOGISMOS
`arith` is one binary op (cannot chain × then +), `scaleK` has no
intercept, METRON `lin` puts the slope on the row index, APOGRAPHE `int`
adds a constant only vertically, TAXIS relations are percents/binary.
Dual-unit exports live in that corner (temp_c/temp_f, wind_mph/wind_kph,
pressure_mb/pressure_in …), as do calibrated sensor pairs and °C→K
(intercept-only).

**Twin-rounding twist.** APIs round each twin independently from one hidden
exact value, so `round(1.8·printed_C + 32) ≠ printed_F` on 15–45% of rows
(india lane: temp 38/124, dewpoint 52/124). The twin is not redundant — but
its entire extra information is a **ternary rounding residual**. SYZYGIA
fits (a, b, mode) in exact BigInt rationals with every residual in
{−1, 0, +1} ulp, drops the column, ships one residual char per row on a
`§N` line; exactly-affine pairs ship no line. Reader: stateless
multiply-add + round + ±1-ulp nudge (SYLLOGISMOS scaleK burden class; no
carried state, a slip damages one cell). Up to 8 drops; sources never
dropped; plain + German; greedy drop admission by true contract+reduced
tokens; whole-input byte-exact restore arbitrates; house gate
(candidate < AKO2 ∧ APO on source, then < full TAGSTACK+SIBLING frontier,
else measured best parent returned).

**Verification.**

- Red team (`bench/x57/redteam/`): 28/28 seeded cases (exact affine,
  twin-rounded, intercept-only, scale-only, negative slope, TSV/CRLF,
  quoted fields, duplicate header names, German format, truncating

  byte-exact on india + 15 plain-style red-team cases. It caught two real
  bugs during development (omitted duplicate header names; signed-zero

  TS restore + red team, not the twin (disclosed).

**Claim taxonomy.** Domain-integral mechanism, lane-bound member evidence,
frontier-grade only if the full gate lands (see receipts). Not solved in
general; biggest failure surface: reader arithmetic slips on long columns
(one cell each, but silent). Biggest uncertainty: lane mass (one frozen
real export; the shape is every dual-unit API dump, counted honestly as a
class, not a corpus).

## 4. Negative space this turn (source-checked, not re-proposable)

- Periodic/crossed categorical columns: **owned by KOLUMN** (`Qp` cycles,
  `G` periodic deltas) — killed at source-read.
- Pure proportional dual columns (km/mi): SYLLOGISMOS `scaleK` — but
  twin-rounded scale pairs fail scaleK's exact verification too; SYZYGIA's
  residual alphabet covers them (wind/gust/pressure pairs on india).
- Amortization (multiplicative-affine recurrence): kept for a later turn;
  real sample found (bank-export fragment, 36 messy rows) is too short to
  fit-verify the generator rounding conventions this turn.
- Toeplitz/separable grids, rank columns, moving windows: unowned but
  lane-weak or reader-heavy; recorded, not built.
- Modal shortcut + detector: "the second unit column is redundant,
  recompute it" — the detector is exact per-row verification, which is
  what revealed twin-rounding (38–52 violations per pair) and forced the
  residual mechanism. Shipping the naive exact form would have been the
  H∂ failure: plausible, wrong on a third of rows.
